# VIN для всех стран — план цепочки источников (владелец 15.11: «Будут все страны !!!»)

Принцип: по одному маленькому модулю на источник; `ua_vin_decode.fields` идёт по цепочке, источник выше
побеждает, следующие только дополняют пустые поля. Берётся только точное совпадение (та же машина) или официальная
расшифровка без ошибок — никаких догадок. Марку по первым 3 знакам уже даёт `vin_brand`.

| # | Источник | Страны | Цена | Статус |
|---|----------|--------|------|--------|
| 1 | Лоты корейского аукциона (`ua_vin_lots`, video/korea/lots.json) — точный VIN | Корея (и любые машины, выставленные там) | бесплатно, свои данные | пакет crm_new_car_vin_003 готов |
| 2 | Архив VIN прошлых лотов (сборщик копит индекс) | то же, но и давно купленные | бесплатно | предложение |
| 3 | NHTSA vPIC (официальная база минтранса США) | машины рынка США, многие Европа/Япония/Корея экспортные | бесплатно, без ключа | установлено |
| 4 | Японский номер кузова (не 17 знаков, напр. ZVW30-1234567): код модели → модель по данным японского аукциона | Япония | бесплатно, свои данные | нужна проба: какие японские лоты у нас есть |
| 5 | Платный глобальный расшифровщик Vincario (бывш. vindecoder.eu) | Европа, Китай, ОАЭ и др. | платно (по отзывам ≈0,25 $ за запрос; 20 пробных бесплатно); нужен аккаунт владельца и ключ | только предложение |

Проверено (15.11): официальной бесплатной базы расшифровки VIN для Европы/Китая/ОАЭ нет; бесплатные «открытые»
сервисы — неофициальные, без гарантий (не берём). Источники: NHTSA vPIC API docs; vincario.com/api-docs, vincario.com
блог о ценах; обзоры JDM-номеров кузова (carsxe.com, cardog.app/docs/chassis).
