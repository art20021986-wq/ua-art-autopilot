# VIN для всех стран — план цепочки источников (владелец 15.11: «Будут все страны !!!»)

Принцип: по одному маленькому модулю на источник; `ua_vin_decode.fields` идёт по цепочке, источник выше
побеждает, следующие только дополняют пустые поля. Берётся только точное совпадение (та же машина) или официальная
расшифровка без ошибок — никаких догадок. Марку по первым 3 знакам уже даёт `vin_brand`.

| # | Источник | Страны | Цена | Статус |
|---|----------|--------|------|--------|
| 1 | Лоты корейского аукциона (`ua_vin_lots`, video/korea/lots.json) — точный VIN | Корея (и любые машины, выставленные там) | бесплатно, свои данные | пакет crm_new_car_vin_003 готов |
| 2 | Архив VIN прошлых лотов (сборщик копит индекс) | то же, но и давно купленные | бесплатно | предложение |
| 3 | NHTSA vPIC (официальная база минтранса США) | машины рынка США, многие Европа/Япония/Корея экспортные | бесплатно, без ключа | установлено |
| 4 | Японский номер кузова (не 17 знаков, напр. ZVW30-1234567): код модели → модель по данным японского аукциона | Япония | бесплатно, свои данные | нужна проба: какие японские лоты у нас есть |
| 5 | Платный глобальный расшифровщик Vincario (бывш. vindecoder.eu) | Европа, Китай, ОАЭ и др. | платно (по отзывам ≈0,25 $ за запрос; 20 пробных бесплатно); нужен аккаунт владельца и ключ | только предложение |

Проверено (15.11): официальной бесплатной базы расшифровки VIN для Европы/Китая/ОАЭ нет; бесплатные «открытые»
сервисы — неофициальные, без гарантий (не берём). Источники: NHTSA vPIC API docs; vincario.com/api-docs, vincario.com
блог о ценах; обзоры JDM-номеров кузова (carsxe.com, cardog.app/docs/chassis).

## 10 разных источников (владелец 15.11: «найди 10 независимых источников разных»)

| # | Источник | Откуда данные | Страны | Цена/доступ | Оценка |
|---|----------|---------------|--------|-------------|--------|
| 1 | Лоты корейского аукциона (наш сборщик) | сам аукцион, точный VIN | Корея | бесплатно, уже на сервере | готов (crm_new_car_vin_003) |
| 2 | NHTSA vPIC (минтранс США) | официальные данные производителей | рынок США + экспортные | бесплатно, без ключа | установлен |
| 3 | Відкриті дані МВС України (data.gov.ua, реєстр ТЗ з VIN з 2021) | державна реєстрація | машины, уже регистрированные в Украине | бесплатно, официально | проверить пробой |
| 4 | Японский аукцион (номер кузова) | сам аукцион | Япония | бесплатно (свои данные) | проверить, есть ли данные |
| 5 | Сайты характеристик по модели (Auto-Data, UltimateSpecs и др., уже в TASK111) | каталоги по модели/году | все | бесплатно, уже на сервере | не по VIN: дополняет после того, как модель известна |
| 6 | auto.dev Global VIN Decode | свой каталог | весь мир (заявлено) | 1 000 запросов бесплатно, дальше платно; нужен ключ | проверить пробой |
| 7 | Vincario (бывш. vindecoder.eu) | свой каталог, Европа | Европа и др. | платно, 20 пробных; нужен ключ | проверить пробой |
| 8 | CarMD Free VIN Decoder API | свой каталог (США) | США | бесплатный тариф, ключ | вероятно дублирует №2 |
| 9 | Wenmar Open | не раскрыт (похоже на NHTSA) | США | бесплатно, без ключа | неофициальный, не берём без проверки |
| 10 | Cardog (японские номера кузова) | свой каталог | Япония | API, условия уточнить | проверить пробой |

Не подходит: корейский 자동차365 (официальный, но только с личной авторизацией, без API на data.go.kr).

Предложение: проба только чтения — взять VIN машин из CRM с уже заполненными полями и сравнить ответы бесплатных
источников (1, 2, 3, 6-free, 9) с тем, что в CRM; ставить в цепочку только те, что совпадают.
