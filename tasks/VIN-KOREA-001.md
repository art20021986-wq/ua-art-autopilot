# VIN-KOREA-001 — корейский VIN расшифровывается полностью

Владелец 15.11 09:18 (Таиланд), скрин: «Создать новое объявление» → VIN KMHL141EBNA246813 → карточка UA-0025 получила
только «Марка: Hyundai». «Очень плохое расшифрование… Разберись немедленно и прими максимальные меры. Так, чтобы я
минимум вносил информацию.»

Причина: VIN корейского внутреннего рынка (без контрольной цифры, 9-й знак «B»). Американская база NHTSA vPIC,
которую использует бот (NEW-CAR-VIN-SPEC), его не понимает (ошибка, год «1992») — и правильно отброшена.

План:
1. Проба (только чтение) `cloud/vin_korea_probe_001`: что знает корейский аукцион (jpauto, кабинет владельца) —
   лоты с VIN и моделью/годом/объёмом/КПП; насколько первые знаки VIN определяют модель и двигатель; сверка с тем,
   что владелец вручную внёс в CRM по прежним корейским машинам; есть ли в кабинете история покупок с VIN.
2. По итогам — модуль расшифровки корейских VIN (без сторонних библиотек), подключённый вторым источником после NHTSA;
   ничего не заполнять наугад. Новых кнопок нет.
3. Проба установки → «да» владельца → установка по очереди координатора.
