# KOREA-HOW-SYNC-001 — блок «5 кроків» на korea.html следует за главной (владелец, 2026-11-11, «пункт один»)

Владелец: на главной в блоке будут заголовки «Корея» и «прочие страны»; на странице Кореи блок должен
обновляться сам вслед за главной.

Решение: копия блока остаётся в HTML korea.html (поиск, без JS). Сразу после неё — маленький скрипт:
загружает /video/index.html и ставит на место копии блок <section class="ua-how"> с главной; при ошибке
остаётся копия. Перевод нового блока делает языковой скрипт сайта сам (следит за добавленными узлами).
Главная и чужие модули не меняются. Пакет cloud/korea_how_sync_001.

Владелец (2026-11-11): «то, что для Кореи, переносим для Кореи внутрь» — на korea.html только часть «Корея».
Разметка блока главной — пакет cloud/home_steps_001 (другая сессия): переключатель .ua-cc, части
[data-ua-for="korea"|"other"], стили в <head> как <style id="ua-home-step…">, скрипты блока внутри секции.
Скрипт korea.html (R2): убирает .ua-cc и все [data-ua-for] кроме "korea", добавляет стили ua-home-step* один раз,
перезапускает скрипты блока (цены Кореи из /video/korea/logistics.json). Проверено в Chromium на их edit_home.
Эти имена менять нельзя без правки cloud/korea_how_sync_001.
