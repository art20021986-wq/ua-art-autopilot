# HOME-PHOTO-001 — кнопка «Фото главной страницы» в CRM

Владелец, 2026-10-28: «Добавь в CRM кнопку „Фото главной страницы“, чтобы я мог
загружать туда фотографию и она отображалась на главной странице, отцентрована
красиво: сам автомобиль по краям, чтоб центрировался, убирал лишнее.»

## Проба HOME-PHOTO-PROBE-20261028 (коммит 1288569)
- Бот: python3.10, `start_safe.py` (always-on 266084); python-telegram-bot 22.8.
- На сервере уже есть Pillow 10.4, OpenCV 4.10 (contrib, с `cv2.dnn`), numpy — новых библиотек не нужно.
- Меню владельца: `team_bot.main_menu` → `cars_ui.with_stats_button`; кнопка «Сотрудники» только у владельца.
- Главная `video/index.html` 289b97d2: один первый экран, фото `/video/order/audi_owner.jpg`, CSS `ua-home-audi-001`.

## Решение
Пакет `cloud/home_photo_001` (README): три новых модуля (обрезка / запись на сайт / диалог бота),
дописанный в конец `cars_ui.py` блок и модель YOLOX-S из OpenCV Model Zoo (Apache-2.0).
Владелец видит результат обрезки и подтверждает — только тогда меняется главная.

## Шаги
1. Превью `HOME-PHOTO-PREFLIGHT-20261028` (ничего не меняет).
2. «Да» владельца → установка `HOME-PHOTO-INSTALL-20261028` (бэкап, пауза бота, откат готов).
   Сайт установкой не меняется.
