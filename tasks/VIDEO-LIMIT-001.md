# VIDEO-LIMIT-001 — видео в карточке: время и объём по максимуму

Владелец 19.11 (через координатора): «видео увеличить там количество времени, объем по максимуму, сколько это можно на
данный период времени».

Сейчас (код бота cars_ui.py): одно видео до 19 МБ (_V140_PREDEL_VIDEO, текст «максимум 20 МБ»), длительность не
ограничена, до 100 видео в карточке (диагностика — до 10). 20 МБ — предел Telegram на скачивание ботом через облачный
Bot API (getFile). Свой сервер Telegram Bot API (tdlib/telegram-bot-api, --local) — до 2000 МБ.

Шаг 1 — проба только чтения VIDEO-LIMIT-PROBE-20261119 (cloud/video_limit_probe_001): инструменты сборки, память,
localhost внутри задачи, связь с Telegram, видео на сайте (размеры, длительность), код скачивания/сжатия видео,
нагрузка CPU аккаунта. Дальше — план владельцу через координатора.
