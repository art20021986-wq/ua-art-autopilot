# CARD-DIAG-001 — пропала «Комплексная диагностика» на карточке Mercedes-Benz B-Class

Запрос владельца (2026-11-05): на карточке Mercedes-Benz B-Class (в наличии)
пропала кнопка «Комплексная диагностика». Найти причину, вернуть, проверить
остальные карточки, чтобы такого больше не было.

План:
1. Проба только для чтения CARD-DIAG-PROBE-20261105 (cloud/card_diag_probe_001):
   какие карточки без кнопки, данные диагностики в CRM, какой код ставит кнопку.
2. Минимальная правка причины + тест на все карточки.
3. Установка через main Actions после «да» владельца.

## Результат (пробы CARD-DIAG-PROBE-20261105, -20261106, -20261106-R2, только чтение)
- Mercedes-Benz B-Class в наличии — UA-0007. Кнопка «Комплексная диагностика» есть
  на всех 19 карточках каталога (ru/ua), в CRM-карточке кнопка тоже на месте.
- Страница диагностики UA-0007 пустая, потому что материалов диагностики у UA-0007
  никогда не было: в CRM пусты описание диагностики, фото, видео и ссылка OBD;
  папки video/diag/UA-0007 нет; во всех копиях CRM с 2026-08-23 то же самое;
  в журнале изменений нет ни одной записи этих полей (удалений не было).
- Большая страница 24.08 (38 КБ) была ошибочной копией основной карточки
  (фото/описание машины + «Диагностика готовится»), не диагностикой.
- Фраза «було проведено діагностику по ходовій частині…» — из текста техсостояния,
  он на основной карточке и не пропадал.
- Остальные карточки: материалы диагностики есть только у UA-0001 (1 фото) и
  UA-0018 (видео, текст, OBD); на сайте они совпадают с CRM.
Итог: ничего не пропало, восстанавливать нечего; правка кода не нужна.
Чтобы страница заполнилась — внести материалы в CRM: карточка → «Комплексная диагностика».
