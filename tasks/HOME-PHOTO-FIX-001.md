# HOME-PHOTO-FIX-001 — кнопка «Поставить на главную» не ставит фото

Владелец 15.11 08:55 (Таиланд): бот CRM → «🖼 Фото главной страницы» → обработка прошла (Audi A6) →
«✅ Поставить на главную» → «Не получилось поставить фото. Главная страница не изменена.»
«Дай задачу, чтобы такого больше не повторялось.»

Причина: модуль Кореи (10.11) перенёс фото главной в свой блок над «Авто в наявності»; публикатор
искал фото только в первом экране (HOME_PICTURE:0).

Сделать: публикатор находит фото по его признаку (единственная главная картинка страницы), где бы
блок ни стоял; тесты на живой копии главной и с модулем Кореи. Новых кнопок нет. Пакет
`cloud/home_photo_fix_001`. Проба → «да» владельца → установка по очереди координатора.
