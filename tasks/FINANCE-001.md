   `https://t.me/ulf_agent_bot?start=387da37d-92d7-4a21-8c69-13c14030906d=site` — ссылку не менять.
3. Переходы по ссылкам партнёров видны в CRM-боте владельца.
4. Оформление как у ведущих мировых автодилеров, чтобы инструментом пользовались.
5. SEO — главное: максимально полная и правильная индексация; данные о партнёре — с официального сайта
   Хапай Авто (hapai.kiev.ua).
6. Кнопка «Кредити та лізинг» на ВСЕХ карточках авто — в наличии, в пути, на пароме и будущих.

## Решение (best practice, сверено)
- **Отдельная индексируемая страница** uk/ru (не всплывающее окно): `seo/ua/kredyt-lizynh-avto.html`,
  `seo/ru/kredit-lizing-avto.html`. Делает её существующий генератор посадочных страниц
  (`ua_seo_landings`) — значит автоматически: sitemap, hreflang uk/ru, canonical, Google sitemap ping, IndexNow.
  Разметка schema.org: BreadcrumbList + `LoanOrCredit` (лизинг, поставщик — партнёр) + AutoDealer.
  Видимые ответы на частые вопросы (FAQ-разметка Google показывает только гос/мед-сайтам — делаем текстом).
- **Ссылка партнёра** — `rel="sponsored noopener"`, новая вкладка (правило Google для партнёрских ссылок).
- **Логотип** — файл, присланный владельцем (сайт партнёра закрыт для автоматического чтения, 403),
  хранится у нас (не тянем с чужого сервера), 480×66, с размерами и alt; на тёмном фоне карточки.
- **Учёт перехода** — существующая аналитика сайта (`analitika_yadro`, `/ua/a.js`, уже стоит на всех
  страницах и шлёт события через `sendBeacon`): новый тип события «finance» с id партнёра. Без новой базы
  и нового адреса на сервере (база заявок MySQL принимает только свой набор таблиц). Без личных данных.
- **CRM-бот**: «Клиенты» → «Кредити та лізинг»: число переходов (сегодня / 7 дней / всего) и последние
  переходы (время, партнёр, откуда). Отдельный модуль, как «Заявки с сайта».
- **Партнёры — данные** (один модуль-список): добавить кредит/лизинг = добавить запись, код не трогать.

## Порядок этапов
0. ТЗ (этот файл).
1. **Проба только чтение** (раннер + сервер, ничего не пишет): страницы hapai.kiev.ua (условия, логотип);
   на сервере — хеши и текущий вид модулей из таблицы, где хранятся заявки, причина сбоя синхронизации карточек.
2. **Релиз 1 — страница + учёт переходов + CRM-бот + кнопка на подборе.** Предпросмотр → макет телефона
   владельцу → «Да» → установка → живая проверка (страница 200, в sitemap, клик записан, бот показывает).
3. **Релиз 2 — починка синхронизации карточек** (без неё изменения карточек не доходят до сайта, сбой
   UA115_UNAPPROVED_EXTERNAL_HOST www.googletagmanager.com с 2026-11-01). Отдельное «Да».
4. **Релиз 3 — кнопка на всех карточках** (через обработку карточки при публикации; все карточки
   переиздаются один раз). Отдельное «Да», проверка до/после: меняется только новая кнопка.

## Важно для владельца
- Кнопка «Розрахувати» на подборе исчезнет (заменяется). Форма заказа под карточками остаётся
  («Обрати інший автомобіль»), быстрая заявка «Отримати пропозицію…» остаётся.
- Тексты об условиях партнёра — только с его официального сайта; на сайте партнёра в разных разделах
  аванс 15% и 20% — берём 20% (как дал владелец) с пометкой «умови уточнюйте у партнера».
