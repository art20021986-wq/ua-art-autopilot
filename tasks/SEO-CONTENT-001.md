## 4. Новая страница «Nissan Note з Японії» (uk/ru, `seo/ua/nissan-note-yaponiya-kyiv.html`)
- Заголовок: **Nissan Note з Японії під замовлення**
- Вступ: Nissan Note — компактний хетчбек для міста. Під замовлення возимо Note 2018–2023 років з Японії: покоління E12
  (до 2020) і E13 (з кінця 2020). Найпопулярніша версія — e-Power: бензиновий двигун 1.2 лише заряджає батарею, а колеса
  крутить електромотор, тому машина їде як електромобіль і витрачає мало пального в місті.
- Покоління: E12 (2018–2020) — бензин 1.2 або e-Power, передній привід. E13 (з кінця 2020) — тільки e-Power, передній
  або повний привід.
- Кермо (утверджённый текст): Праве кермо, як продають у Японії, переробляють на ліве кермо наші колеги в Грузії.
  Понад 20 років досвіду.
- Питання: «Чи можна Nissan Note з лівим кермом?», «Скільки коштує Nissan Note з Японії під ключ?» (ціна фіксується в
  договорі, без доплат). Кнопка «Підібрати Nissan Note» → форма з моделлю.

## 6. Новая страница «Авто з Кореї на газу (LPi)» (uk/ru)
- Заголовок: **Авто з Кореї на заводському газу (LPi)**
- Вступ: У Кореї багато седанів продають із заводським газовим двигуном LPi. Газову систему ставлять на заводі разом із
  двигуном, а не після продажу.
- «Чим LPi відрізняється від встановленого ГБО»: двигун від початку розрахований на газ; рідкий газ подається в двигун
  форсунками під тиском; машина працює тільки на газу — бензинового бака немає; окреме перемикання не потрібне.
- Моделі: Kia K5 2.0 LPi і Hyundai Sonata 2.0 LPi (2018–2023) — посилання на їхні сторінки; інші моделі — під запит.
  У Sonata DN8 балон-«бублик» у ніші запасного колеса залишає багажник вільним.
- Навіщо: газ в Україні дешевший за бензин — помітна економія на щоденних поїздках.
- Кнопка «Підібрати авто на газу».

## 3. Страницы диагностики (`UA-XXXX-diag.html`)
`<meta name="robots" content="noindex,follow">` в общем шаге SEO публикации: страница остаётся для посетителей
(ссылка из карточки), но не показывается в Google отдельно. Применится при следующей публикации карточек.

## 2. Карточки вне индекса
Страницы моделей уже показывают машины каталога; у каждой карточки теперь две языковые страницы в карте сайта
(CARD-LANG-001). Новых правок не делаем — проверим индекс через 1–2 недели. Страницы Mercedes E-Class остаются
(движок страниц моделей их не удаляет по правилу «не терять адреса»).

## Решение (владелец «Да» 2026-10-31) — пакет `cloud/seo_content_001`
- `ua_seo_order_models.py` (данные): `TOPICS` (Nissan Note, LPi — uk/ru) и `ORDER_EXTRA` (заголовок, «Що ви отримуєте»,
  два вопроса). Вопрос про постановку LPi на учёт в черновик не входил — не добавлен.
- `ua_seo_landings.py` (правки): адрес страницы-темы, `topic()`, запись в `pages()`, ссылки со страницы Японии и
  страниц K5/Sonata, новые блоки страницы «Авто під замовлення».
- `ua_seo_metadata.py` (правка): `noindex,follow` для `UA-XXXX-diag.html`, SEO_REVISION → SEO-CONTENT-001.
- Пробная сборка рендерит все страницы с живым каталогом (ожидаются 4 новые) и проверяет страницу диагностики.
