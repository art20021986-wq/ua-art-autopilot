# CRM-VOICE-FILL-001

STATUS: OWNER_APPROVED

- Голос из открытой карточки изменяет только её `card_id`.
- Без открытой карточки голос не создаёт новую: бот просит выбрать карточку.
- Заполняются пустые поля; заполненные меняются только после «измени/исправь/замени».
- Одна расшифровка, 0 LLM-токенов, общий лимит распознавания 15 секунд.
- Повтор одного Telegram-сообщения не выполняет запись повторно.
- После записи доступна отмена последнего голосового изменения.
- Выход в список или главное меню сбрасывает активную карточку.
- Установка не меняет `crm.db`, сайт и UA-0009; только код и перезапуск бота.

Acceptance: «привод передний» в открытой UA-0009 дополняет UA-0009 и не увеличивает число карточек.
