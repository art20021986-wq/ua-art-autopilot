# LEAD-FOLDERS-001 — лиды по папкам источников и «Оформить» → Клиенты

## Задача владельца (2026-11-06)
- Лиды приходят в бот для клиентов и параллельно в CRM-бот; их надо раскладывать по папкам
  строго по источнику: «Карточки» (авто в наличии, внутри — лиды), «Под заказ: Корея»,
  «Под заказ: Япония», «Под заказ: Китай» и т. д. по всем источникам + общая папка.
- Лиды обрабатываем; когда сделка/договор/подписание — кнопка «Оформить», и лид
  автоматически переходит в «Клиенты» CRM-бота.
- «Клиенты» — та же оболочка, те же папки один в один; сверху — статистика по клиентам.
- Тест владельца: сегодняшняя карточка → «Оформить» → договор → лид в «Клиентах».

## Шаг 1 — проверка на чтение (LEAD-DESK-PROBE-20261106-R5)
Исходники бота для клиентов (client_ui.py, visits.py), раздела «Клиенты» (cars_ui.py),
модулей заявок; счётчики клиентов по источнику/дню (без личных данных).
