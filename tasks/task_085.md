- у `UA-0011` неизменны VIN, цена, описание, фотографии, видео, диагностика,

- runtime LLM tokens = 0.

## Постоянный контракт этапов

- публичный renderer использует allowlist полей текущего этапа и никогда не
  показывает payload другого этапа;
- центральная запись `status` атомарно очищает несовместимые поля только при
  реальном переходе между этапами;
- повторная запись того же этапа идемпотентна и не стирает корректные данные;
- прямой SQL/старый callback не может сохранить контейнер или ETA при этапе
  Корея;
- при переходе в Грузию старый морской ETA не наследуется, а новый срок
  рассчитывается только из фактического перехода;
- любой FAIL после записи вызывает точный rollback к preimage.
