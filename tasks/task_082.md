## Доказанная причина

Свежий Gate A TASK 075 подтвердил:

1. Ранее CRM UA-0011 имела канонический `status=sea_loaded`, 35 фото и этап 2.
2. Свежий GET-only снимок 29.08.2026 07:46:57Z доказал регрессию: UA-0011 опубликована, имеет 35 фото и VIN 4289, но её `status` ошибочно стал `kr_bought`; поле `stage` пустое.
3. Каталог был собран в момент, когда media mapping ещё не содержал главное фото.
4. Legacy renderer при пустом media mapping не блокировал публикацию, а выводил узкую текстовую fallback-карточку без фотографии.
5. После завершения media sync каталог автоматически не пересобрал эту карточку полным единым шаблоном.

Следовательно, исправление состоит из двух строго ограниченных действий: вернуть UA-0011 единственное поле `status` из `kr_bought` в `sea_loaded`, затем пересобрать каталог после media sync единым шаблоном.
