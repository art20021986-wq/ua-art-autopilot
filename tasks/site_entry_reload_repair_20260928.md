# Повторные сбои входа из TikTok и Chrome

Запрос владельца: найти и устранить причину недоступности оплаченного рекламного входа. REDO не использовать; работать с основным www.uaart.com.ua через доступные ресурсы.

Подтверждение: 28 сентября 2026 в 14:21:31 UTC сервер получил SIGINT/SIGTERM. В это же окно запросы с TikTok-маркерами получили 499/502 и ожидали до 25.600 с. Actions run 36435344361, job 108971714134 вызвал /reload/ и завершился таймаутом. Это подтверждённый эпизод; причина всех прежних мобильных сбоев не установлена.

Исправление: GSC и sitemap installers перезагружают приложение только после добавления отсутствующего точного static mapping. При совпадающем mapping проверяют публичный ответ без записи и reload; конфликт или некорректный ответ API завершают без записи. GSC использует существующую очередь ua-art-production-writer. Перед обоими installers запускаются сетевые регрессионные тесты с подменой urllib; тесты не обращаются к production.

Проверить перед завершением: локальные тесты, main Actions с UNCHANGED_RELOAD_SKIPPED и PASS, фактическое открытие основного сайта. Не перезапускать приложение специально для теста. Файлы сайта, CRM, DNS и рекламная кампания не требуют изменения для этой правки.


Результат: PR228 слит в main (a6a18b3081eb4ffd58f0170688aaa749e5d35dbd). Main Actions 36456522813 завершился SUCCESS: UNCHANGED_RELOAD_SKIPPED и SEO_SITEMAP_ROUTE_PASS. Chrome открыл главную с синтетическими рекламными параметрами, каталог и UA-0018; цены JSON, языковой JS, sitemap и Google verification вернули HTTPS 200.
