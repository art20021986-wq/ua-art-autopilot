# AI-SEARCH-001 — видимость сайта в ИИ-чатах

Владелец, 2026-10-19: чтобы ChatGPT и другие ИИ-чаты правильно индексировали сайт и
советовали его по запросам «авто под заказ / из Кореи в Киев». ТЗ утверждено («Да»).

Пункты:
1. Проверка (только чтение): журналы сервера — какие роботы ИИ/поиска заходят, ответы сайта роботам.
2. robots.txt — явный доступ роботам ИИ-поиска (если проверка покажет, что нужно).
3. IndexNow — мгновенное оповещение Bing (→ ChatGPT/Copilot) о новых/снятых машинах.
4. Страница-ответ «Авто под заказ из Кореи в Киев» uk/ru: текст, этапы, частые вопросы.
5. Данные о компании на главной (разметка: адрес, телефон, часы).
6. Ежемесячный замер упоминаний в ChatGPT/Perplexity.

Владелец: Bing Webmaster Tools (импорт из Search Console); восстановить доступ Search Console.
Каждая запись на сайт — отдельное «да». Не делаем: llms.txt, скрытые тексты, правки карточек.
