# JAPAN-CLASSICS-2000

Владелец, 2026-10-30: «В Японии раритетные автомобили с 2000 по 2003 год. Выбери 8 фотографий разных
с левым рулём, подчёркиваю, важно.»

Решение:
1. Чтение Commons (STANDARD, `cloud/model_gallery_001/classics2000.py`): 18 редких моделей 2000–2003,
   поиск по названию и по салону; год в имени файла 2000–2003 или без года; миниатюры 640 px.
2. Отбор глазами: 8 разных машин, у каждой левый руль виден на фото.
3. Название карточки — «Раритетное авто», без годов (владелец, 2026-10-30). Превью владельцу;
   запись на сайт только после «да».
