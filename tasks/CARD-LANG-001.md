# CARD-LANG-001 — ТЗ: отдельные адреса украинской и русской версии карточек авто (SEO, пункт 1)

Владелец, 2026-10-30: «Дай мне отдельное ТЗ под пункт 1 и начни с него… после пункта 1 продолжай остальные пункты».
Основание: SEO-AUDIT-20261030, проверка CARD-LANG-PROBE-20261030 (код генератора и живая карточка UA-0013).

## 1. Что есть сейчас (факты из проверки)
- Карточка `/video/UA-XXXX.html` собирается на русском: `<html lang='ru'>`, русские title/description/h1/текст.
  Украинский текст хранится в атрибутах `data-uk…` и в словаре `ua-site-languages.js` (≈1 700 фраз);
  скрипт в браузере переводит страницу **на том же адресе**, по умолчанию — на украинский.
- Значит, один адрес отдаёт два языка: в исходном HTML — русский, после скрипта — украинский. Google так делать
  не советует: у каждой языковой версии должен быть свой адрес, `hreflang` между ними и свой canonical.
- Все записи карточки проходят через одну точку: `publikaciya._zapisat_atomarno` → `site_ge_inject` →
  `ua_seo_metadata.normalize` → `ua_seo_sitemap.sync_after_write`; карта сайта — `ua_seo_sitemap`/`ua_seo_index`.
- Рядом лежат копии с хешем (`UA-0001-00cf71c0.html`) и страницы диагностики — в этом ТЗ не меняются.

## 2. Цель
Каждая карточка доступна как две полноценные статические страницы на своих адресах:
- **украинская** — основной адрес `/video/UA-XXXX.html` (`lang="uk"`, украинский title/description/h1/текст) —
  именно её сейчас видят посетители по умолчанию, адрес и ссылки не меняются;
- **русская** — `/video/UA-XXXX-ru.html` (та же папка: фото, видео и ссылки работают без переделки путей).
Между ними — `hreflang` (uk, ru, x-default = uk), у каждой — свой canonical. Грузинский остаётся как сейчас
(перевод скриптом), отдельный адрес — по желанию позже.

## 3. Решение (модули, у каждого одна задача)
1. **`ua_card_lang.py` (новый, чистые функции, без сторонних библиотек):**
   `translate(html, 'uk')` — русская карточка → украинская: текст по словарю из `ua-site-languages.js`
   (один источник переводов, без второго словаря), атрибуты `data-uk*`, несколько правил карточки
   («Фото N / M», «обновлено …», «Позвонить …»); `lang`, canonical, `hreflang`.
   `untranslated(html)` — список оставшихся русских фраз (проверка качества).
2. **Точка записи карточки** (`publikaciya._zapisat_atomarno` — одна врезка по образцу существующих блоков):
   для карточки пишет украинскую версию на основной адрес и русскую — на `-ru` адрес.
   Если перевод неполный — основной адрес остаётся как сейчас (русский), запись в журнал; публикация никогда
   не блокируется.
3. **`ua_seo_sitemap.py`**: русские адреса карточек попадают в карту сайта (IndexNow и Google — как сейчас).
4. **`ua-site-languages.js`** (одна маленькая правка): на странице с `hreflang` кнопки UA/RU переходят на адрес
   нужного языка, а не переводят страницу на месте; без явного выбора страница показывается на своём языке.
   На остальных страницах поведение не меняется.
5. **Перегенерация всех текущих карточек** при установке (из их сохранённых русских версий), с проверкой
   до/после: цены, фото, видео, VIN, этап доставки, кнопки и заявки — без изменений.

## 4. Порядок работы
0. Проверка только на чтение: все места, которые пишут файлы карточек (чтобы не пропустить второй путь записи),
   и код словаря/скрипта языков. — **начато.**
1. Пакет + тесты: каждая живая карточка переводится полностью (`untranslated` пусто), разметка цела, ссылки работают.
2. Снимки украинской и русской карточки на телефоне — владельцу на «да».
3. Пробная сборка на сервере → установка (бэкап, откат, проверки как всегда) → проверка живых страниц.
4. Через 1–2 недели — отчёт Search Console: индекс украинских и русских карточек.

## 5. Что не меняется
Цены, CRM, публикация из CRM, фото/видео, страницы диагностики, копии с хешем, каталог и главная
(у них та же схема «один адрес — два языка»; можно сделать следующим шагом — предложение, не часть этого ТЗ).

## 6. Риски и защита
- Неполный перевод → карточка не переключается, остаётся как сейчас; список недостающих фраз — в отчёт.
- Две записи вместо одной → обе атомарные, под тем же замком публикации; откат возвращает обе.
- Google временно видит смену языка на основном адресе → ожидаемо и правильно (сейчас он и так видит украинский после скрипта).
