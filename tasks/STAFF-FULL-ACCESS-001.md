# STAFF-FULL-ACCESS-001 — управляющему те же права, что у владельца

Владелец (2026-11-12): управляющий должен видеть клиентский бот и бот-CRM
точно так же, как владелец, с полными правами в обоих ботах.

## Как сейчас (по исходникам ботов в cloud/)
- Бот-CRM: роли «Владелец» / «Управляющий администратор» / «Менеджер».
  Владелец — один, задан `OWNER_ID`. Часть кнопок и действий
  (коды приглашения, блокировка сотрудников и др.) — только у владельца.
- Клиентский бот: «админ» один — `ADMIN_IDS = [MANAGER_CHAT_ID]`.
- Приглашение управляющему (@Beetle204, код 812DFF) создано 2026-11-05;
  проба 2026-11-05 R8: активен только владелец.

## План (после «да» владельца)
1. Проба (только чтение): найти Telegram ID управляющего по @username
   в базах ботов (после того как он нажмёт «Старт» в обоих ботах).
2. Бот-CRM: `OWNER_ID` → список владельцев (`OWNER_IDS`, старое значение
   остаётся первым). Одна точка в `who()`, остальной код не трогать.
3. Клиентский бот: `ADMIN_IDS` — из списка, а не из одного ID.
4. Установка через автопилот: бэкап, откат, проверка до/после,
   `crm_unchanged`, перезапуск ботов. Владелец проверяет у управляющего.
