## WhatsApp-группа (владелец 17.11 через координатора)
Владелец: авто по его критериям — обычным сообщением в WhatsApp-группу клиента (нельзя удалять), ссылка на группу в CRM-боте.
Проверка по документации Meta (Groups API): группы только у Official Business Account (OBA, «зелёная галочка», по решению Meta),
только номер на Cloud API; группу создаёт бизнес-номер через API, вход по приглашению (шаблон utility), до 8 участников,
до 10 000 групп на номер; писать в группу, созданную вручную, нельзя; оплата за сообщение. Неофициальные WhatsApp Web-боты —
нарушение правил, бан номера. Варианты владельцу (cloud/photos/33-AUTOSEARCH-WHATSAPP.png): А — личные сообщения
через Cloud API (номер, Meta Business, оплата); Б — группы (нужен OBA); В — Telegram + журнал в CRM (работает).
