# AUTOSEARCH-001 — автопоиск лотов в кабинете + уведомление в Telegram (сессия 33)

Владелец 17.11: «автопоиск автомобиль с аукционов в личном кабинете с уведомлением на мессенджер,
WhatsApp или Telegram автоматически. До 10 авто».

## Проба (только чтение, 17.11)
- lots.json на сайте: 3395 лотов (generated_at 2026-11-17T13:26+09:00), обновляется сборщиком korea_auction
  в дни торгов (10/12/14 по Корее, пн–сб); 554 лота без стартовой цены.
- Кабинет video/kabinet.html (ua_client_cabinet.py, сессия 14), API /api/auction/* (ua_auction_web.py, вход по cookie).
- Клиентский бот @UA_artcompany_LLC_bot = lead_bot.py; /start уже понимает метку (context.args).

## План (ждёт «да» владельца, макет cloud/photos/33-AUTOSEARCH.png)
1. Кабинет: раздел «🔔 Автопошук» под «Мої ставки»: марка, модель, рік від/до, пробіг до, ціна до $, паливо,
   колір (списки — как фильтры korea.html сессии 24); «💾 Зберегти пошук», список «Мої пошуки» с «🗑»;
   «📲 Підключити Telegram» / «✅ Підключено · Відключити».
2. Привязка Telegram: одноразовый код (15 мин, хранится только хеш) → t.me/UA_artcompany_LLC_bot?start=<код>;
   бот связывает чат с клиентом. Новый модуль, обработчик /start с кодом стоит перед анкетой, остальное не трогает.
3. Уведомления: задача в клиентском боте раз в 10 мин смотрит, изменился ли lots.json; если да — сверяет
   сохранённые поиски, шлёт только новые лоты (журнал отправленных), до 10 в сообщении + «ещё N».
   При нагрузке PythonAnywhere — работа только чтение одного файла и SQLite, без сети кроме Telegram.
4. CRM-бот: строка «🔔 Автопоиск» в карточке клиента аукциона (владелец и менеджер одинаково).
5. WhatsApp — вторым шагом только по «да» владельца (Meta Cloud API, платно за сообщение).

Модули (новые, маленькие): ua_lot_alerts.py (хранилище + сверка), ua_lot_alerts_bot.py (привязка + рассылка),
правки: ua_auction_web.py (API), ua_client_cabinet.py (раздел), lead_bot.py (одна строка register),
