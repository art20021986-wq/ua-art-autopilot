# TASK 091 — CRM-NUMERIC-SINGLE-CLAIM-091 v1.0

## Команда владельца

Владелец указал обязательный инвариант CRM: **одно исходное число → одно значение → одна ячейка**. После уточнения владелец потребовал не только законспектировать правило, а выполнить исправление.

Наблюдаемый дефект в новой карточке **UA-0015**, VIN **KMHE341DBJA475862**:

- вход: `LPG / 1,999cc / 395,459km / VIN`;
- правильно: объём `1 999 см³`, пробег `395 459 км`, топливо LPG, VIN;
- неправильно: тот же фрагмент `1,999cc` повторно записан как год `1999`.

## Обязательное поведение

- Одно числовое вхождение может быть потреблено только одним полем CRM.
- Физическая единица или явная подпись определяет владельца значения:
  - `cc / см³ / L` → объём;
  - `km / км` → пробег;
  - `$ / USD / грн` → цена;
  - `год / рік / year` → год.
- После назначения числовое вхождение считается использованным и недоступно другим полям.
- Если одинаковое число реально указано дважды отдельными фрагментами, оно может заполнить два соответствующих поля.
- При сомнении поле остаётся пустым; CRM не додумывает значение.
- Правило применяется к тексту, OCR и голосовой расшифровке, ко всем текущим и будущим карточкам.

## Точечное исправление UA-0015

- Другие строки CRM не изменять.
