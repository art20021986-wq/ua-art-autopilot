# KOREA-GALLERY-001 — просмотр фото в карточке лота Кореи, как на карточках каталога

Владелец (через координатора, 13.11): сверху большое фото, снизу лента миниатюр, стрелки и свайп; фото как можно крупнее;
чисто, крупно, контрастно, понятный счётчик; WCAG (alt, подписи кнопок, клавиатура, фокус). Без сторонних библиотек;
сначала проверить, можно ли взять модуль галереи каталога.

## Проверено
Каталог (UA-XXXX): cloud/media_gallery_final_001 — разметка ua_media_gallery (на сервере), стили ua_media_styles.CSS, скрипт
ua_media_script.JS; на живом сайте именно они (сверено). Скрипт каталога запускается один раз при загрузке страницы и
обходит готовые галереи; окно лота рисуется позже — подключить его без переделки общего модуля нельзя (переделка тронула бы
все карточки каталога).

## Решение (cloud/korea_gallery_001, поверх korea.html после KOREA-ENGINE-INSTALL)
- ua_media_styles.py — копия стилей каталога байт в байт (тест сверяет с исходником): вид как в каталоге;
- lot_gallery_style.py — несколько правил окна лота (.kg-*): крупный жирный счётчик 18 px, стрелки небольшие (видимый кружок 32 px, зона нажатия 44×44 px — WCAG; владелец 13.11 «меньше»), место под «×»;
- lot_gallery_script.py — свой маленький скрипт: при отрисовке лота заменяет ленту .kl-photos на просмотр: крупное фото,
  «Фото N / M» (role=status, aria-live), стрелки с подписями (uk/ru/ka), миниатюры — tablist (стрелки/Home/End), свайп,
  alt «<авто> — фото N», остальные фото — из video/korea/gallery/<id>.json;
- lot_gallery_page.py — правка korea.html: блок перед </body>; старая подгрузка gallery(l) из KOREA-ENGINE убрана (её делает просмотр).
Тесты: test_lot_gallery 6/6, test_release 2/2, test_deployment OK. Браузер iPhone 13: Фото 1/40, стрелки, миниатюра 11,
End → 40/40, свайп пальцем 1 → 2, ru подписи, ошибок JS 0. Фото «было/станет»: cloud/photos/24-gallery.png.
Дополнение владельца (координатор 09:54): режим «на весь экран» — как в каталоге: родное окно <dialog> на весь экран
(работает и на iPhone, где Fullscreen API для элементов нет): крупное фото, лента миниатюр снизу (листается), стрелки, свайп,
закрыть «×» / Esc / касание вне фото; фокус — на «×» при открытии и обратно на кнопку «На весь екран» после.
Открывается кнопкой ⛶ «На весь екран» или касанием фото. Браузер: Esc закрывает только полный экран (окно лота остаётся),
стрелки/миниатюры в полном экране работают, ошибок JS 0.
Не делал (можно предложить): маленькие копии фото для миниатюр (сейчас миниатюры — те же фото, грузятся лениво).
