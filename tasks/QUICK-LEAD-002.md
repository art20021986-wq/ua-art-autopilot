# QUICK-LEAD-002 — «Отримати пропозицію в месенджері» над «Розрахувати» на странице подбора

Владелец, 2026-10-26: кнопка над каждой «Розрахувати авто» во всех странах страницы подбора (`video/podbor.html`).
Текст — как на страницах моделей: «Отримати пропозицію в месенджері» (ru «Получить предложение в мессенджере», ka перевод).

Решение (пакет `cloud/quick_lead_002`):
- `order.js`: одна вставка — кнопка `quick-offer` перед «Розрахувати» (модель, страна, название в data-атрибутах).
- `podbor.html`: `<dialog>` с той же короткой формой (имя + телефон, autocomplete name/tel) внутри корня страницы —
  тексты переводит существующий переключатель языка из `order-strings.json` (uk/ru/ka); подключены quick-lead.js/css.
- `quick_assets.py`: один общий скрипт для страниц моделей и страницы подбора (договор: form[data-ua-quick-lead],
  тексты результата в скрытых [data-msg]); страницы моделей переходят на тот же договор (вид не меняется).
- `ua_order/quick.py`: принимает и адрес страницы подбора; у менеджера тип «Короткая заявка (страница подбора)».
- Проверки: 11 + 28 + 2; браузер: кнопка над «Розрахувати», окно с моделью, заявка уходит, «Розрахувати» работает.
- Установка: перезагрузка веб-приложения; живая проверка — неверный телефон со страницы подбора отклоняется по полю
  contact (старая версия отклонила бы по адресу страницы); ничего не сохраняется.
