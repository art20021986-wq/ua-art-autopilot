# NEW-CAR-VIN-001 — «Создать новое объявление» в разделе «🚗 Автомобили» CRM-бота

Владелец, 2026-11-12: «на главной странице [раздела «Автомобили»] напиши „Создать новое объявление“, при нажатии —
„Введите ВИН-код для создания нового автомобиля“, дальше всё как всегда».
Ответы владельца: 1) кнопка вверху экрана «🚗 Автомобили» — да; 2) видят владелец и менеджеры («всё зеркально»);
3) карточка — черновик, на сайте не публикуется.

Поведение:
- Экран «Автомобили» (папки «В каталоге» / «Не опубликованные»): над папками кнопка «Создать новое объявление».
- Нажатие → «Введите VIN-код для создания нового автомобиля».
- VIN (17 знаков ISO 3779, пробелы/дефисы и регистр не важны) → установленный photo_card: марка по VIN,
  карточка создаётся неопубликованной, кнопки «Открыть карточку» / «Редактировать»; VIN уже есть → «Карточка с
  таким VIN-кодом уже существует», ничего не создаётся. Неверный VIN → просьба ввести ещё раз.
- Любая другая кнопка или команда отменяет ввод.

по очереди: оба меняют cars_ui.py.
