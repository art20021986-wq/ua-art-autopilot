# MAKE-SEARCH-001 — поиск в списках «Марка» и «Модель» формы заявки

Владелец 2026-11-06 (форма заявки на podbor.html):
1. При нажатии «Марка» — общий список, вверху поле поиска: человек вводит первые буквы, нужная марка сразу видна.
2. То же для «Модель»: поиск в самом верху списка.
3. В списке модели — одна позиция «Інша модель», только в самом низу. Верхние пункты
   («другая модель», «выберите …») убрать, чтобы не путать.
4. Нажатие «Інша модель» внизу → появляется поле, где модель вводят вручную.
Чистая архитектура, минимальные локальные правки, без сторонних библиотек.

Шаг 1 (только чтение): LEAD-DESK-PROBE-20261106 читает preferences-form.js, preferences-state.js,
order.css, ua_order/preferences.json, podbor.html. Затем — пакет правки, превью, макет владельцу, «да», установка.
