# CRM-TELEGRAM-DELETE-001 — карточка Mercedes не удаляется из Telegram

Владелец, 2026-10-11: «Удалял Мерседес — не удаляется. Найти причину и исправить,
чтобы не повторялось.»

## Что известно (код с сервера от 2026-09-20, свежий не снят)
- `cars_ui.delete_ok` делает голый `DELETE FROM cars WHERE id=?`, затем пишет
  `audit`. При ошибке бот отвечает «Не получилось удалить: <ошибка>».
- `db.connect()` включает `PRAGMA foreign_keys=ON`.
- Главная гипотеза: у Mercedes есть связанные строки (фото/видео/статусы/
  характеристики) в таблицах со ссылкой на `cars` без `ON DELETE CASCADE` →
  SQLite отклоняет удаление (`FOREIGN KEY constraint failed`). Пустые
  черновики при этом удаляются нормально.
- Вторая возможная причина: удаление стирает запись в CRM, но страницы сайта
  не пересобираются (delete_ok не вызывает публикацию) — машина «остаётся» на сайте.
- Не подтверждено, пока нет свежего кода, лога и схемы базы.
