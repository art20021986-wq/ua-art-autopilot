# TASK 108 — восстановление дополнительной спецификации без платного API

## Утверждённая команда владельца

`УТВЕРЖДАЮ TASK108 — БЕЗ ПЛАТНОГО API`

Дата фиксации: 2026-09-03 UTC.

## Цель

Вернуть в карточку автомобиля отдельный раскрываемый блок «Дополнительная спецификация» после основной информации и до VIN. Содержимое блока должно быть сформировано на сервере и присутствовать в HTML/JSON-LD, чтобы поисковый робот мог его индексировать без выполнения JavaScript.

## Неизменяемые правила

- Основные поля CRM заполняет только оператор.
- Автоматический контур может создавать только дополнительные технические параметры.
- Цена, история автомобиля, опции/комплектация, клиентские данные, логистика и медиа не извлекаются и не сохраняются.
- Один смысловой параметр — одна строка; смысловые дубли запрещены.
- Конфликтующие значения не усредняются и не превращаются в диапазон: параметр получает `REVIEW_REQUIRED`.
- Пустая карточка никогда не считается успешной и публичный пустой блок не выводится.
- Публикация автоматом запрещена.
- Производственная БД, публичные файлы и сервисы не изменяются в рамках TASK108.
- Порядок: `BACKUP EVIDENCE → ISOLATED BRANCH/SANDBOX → CANARY UA-0005/UA-0015 → REPORT`.

## Бесплатные источники

1. NHTSA vPIC — бесплатный официальный VIN API, только для идентификации и только при отсутствии критических ошибок декодирования.
2. Каталоги/прайс-листы производителя или их зафиксированные зеркала — основной источник технических фактов после ручной проверки документа и модификации.
3. Независимый нероссийский каталог — только второе подтверждение; автоматическая загрузка выключена, если правила сайта или robots.txt не разрешают её.

Платные API, российские сайты и обход технических ограничений запрещены.
