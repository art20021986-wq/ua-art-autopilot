## Что ставим (один пакет, превью → установка; очередь координатора)
1. Новый сборщик `japan_auction/` (отдельная почасовая задача `japan_ticker_job.py`): поиск Японии с флажком
   «левый руль», карточки лотов (стартовая цена в иенах, фото, VIN), копии фото на сайт (`video/japan/lots/`),
   `video/japan/lots.json` (как у Кореи, цена ¥ и $ по курсу НБУ), `video/japan/feed.json` (неделя для плашки и
   карточки для ленты). Общие части берутся из `korea_auction` (вход, запись файлов, копии фото, неделя).
2. Лента на главной (`korea_auction/ticker.py`, `country_tabs.py`, `job.py`): японские карточки в общей ленте;
   метка страны на каждой карточке (флаг + «Японія»/«Корея», тёмная плашка с золотой рамкой); вкладка «Японія»
   в плашке расписания — дни, число авто, аукционы (вместо «незабаром»).
3. Страница `video/japan.html` — из `video/korea.html` (тексты Японии, лоты из `video/japan/lots.json`, ¥ вместо ₩,
   время «Японія · Київ»), без входа клиента и онлайн-ставок (они в вонах через CRM): в карточке лота —
   «Зв'язатися з менеджером». Онлайн-ставки в иенах — отдельно, по решению владельца.

CRM не меняется. Сайт — только через автопилот: превью, затем установка с бэкапом и откатом.
