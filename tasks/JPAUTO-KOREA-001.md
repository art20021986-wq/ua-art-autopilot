# JPAUTO-KOREA-001 — раздел «Авто из Кореи» через аккаунт владельца на JP Auto Auction

Статус: ждём ключи (владелец добавляет GitHub Secrets `JPAUTO_EMAIL`, `JPAUTO_PASSWORD`).

## Что хочет владелец
- На сайте UA ART — поиск авто из Кореи в дизайне UA ART, параметры поиска
  один в один как на площадке; работа онлайн через аккаунт владельца.
- Название и логотип площадки нигде не показывать.
- CRM-бот не трогать.
- Обновление базы: КАЖДОЕ УТРО, 3 проверки в разное время (решение владельца 2026-11-10;
  торги на площадке идут Пн–Сб, раз в неделю — мало).
  Расписание (владелец): рабочее время Кореи (с 9:00 KST), первая проверка через час,
  затем 2–3 раза каждые 2 часа: 10:00, 12:00, 14:00, (16:00) KST = 03:00, 05:00, 07:00, (09:00) Киев (зима).
- Фото: знаки корейского аукционного зала допустимы; знаков BE FORWARD / JP Auto быть не должно
  (проверено 2026-11-10 — их на фото нет).
- Доступ клиентам — по договору, не массово (мало заходов).

## Что известно
- Вход: обычная форма (почта + пароль), `POST /login/login`.
- robots.txt площадки: `Disallow: /` — заходы делать редкими и аккуратными.
  Риск блокировки аккаунта владельцу сообщён, владелец принял.
- В сеть сессии добавлен хост `jpauto.auction` (2026-11-10).

## Шаги
1. Диагностика (только чтение): автопилот входит, снимает список параметров
   поиска и признаки дня обновления. Ничего на сайт/в CRM не пишет.
2. План раздела: где, как называется, какие кнопки — согласовать с владельцем.
3. Сборка и проверка; запись на сайт — только после «да» владельца.

## Партнёры (добавлено владельцем 2026-11-10, ждёт ответов на вопросы 1–5)
- Клиент регистрируется на сайте → появляется в CRM-боте «Партнёры» → «Новые».
- Менеджер даёт доступ: бот создаёт пароль, менеджер передаёт лично; «Закрыть доступ» — отключение.
- Карточка партнёра: заказы, купленные авто, отслеживание заказа, личная аналитика заходов.
- Общая аналитика партнёров: кто и когда заходил.
- Открытые вопросы владельцу: место раздела в боте; названия кнопок; вход через Apple
  (нужен платный аккаунт разработчика, предложено отложить); место кнопки входа на сайте;
  есть ли уже статусы заказа в CRM.

## Структура (указание владельца 2026-11-10, ждёт утверждения названий кнопок)
1. Главная: на плитке «Корея» (с флагом) снизу подпись «Аукціони онлайн».
2. Страница Кореи:
   - справа вверху — стандартные «Вхід» / «Реєстрація»; регистрация → клиент в CRM (Партнёры);
   - первым — «Дивитися онлайн»: вход по паролю (пароль выдаёт менеджер после договора);
   - ниже — продающий текст: что такое онлайн-аукционы Кореи, какие аукционы
     (без BE FORWARD/JP Auto), депозит 2000 $ входит в стоимость авто, договор → право выбора;
     для автобизнеса — индивидуальные условия, возможность покупать самостоятельно.
3. Внутри — поиск один в один; цена: стартовая в вонах → в долларах.
4. Ставка: клиент в карточке указывает желаемую сумму → заявка в Telegram-группу через бот →
   менеджер ставит вручную от компании → бот уведомляет клиента «ставка сделана».
   Telegram клиента берём из договора.

## Решения 2026-11-10 (продолжение)

- Проверки: 3 раза в день (10:00, 12:00, 14:00 KST), Пн–Сб; воскресенье не проверяем.
- Главная, плитка «Корея»: под фото подпись, что там есть авто онлайн.

  Владелец просит продумать подачу «чтобы вызывала аппетит» — вариант на утверждение.
