Владелец (27.11, дословно): «Ежедневно, каждый день делай что-то для SEO. … чтобы мне предоставляли отчет, что сделали
мы каждый день, что проанализировали, для того, чтобы SEO индексировало нас самостоятельно, Google, без оплаты.»

Каждый день (будит ежедневное напоминание):
1. Проверка, только чтение: `python3 cloud/seo_daily/crawl.py out.json` и `--summary` — все страницы карты сайта
   (ответ, canonical, noindex, язык, title, description, h1, hreflang, разметка, скорость, битые ссылки); robots.txt;
   что нового на сайте; отчёт Search Console (`cloud/gsc_report`, раз в несколько дней) — что не в индексе.
2. Одно-два улучшения по пользе. Код — тесты, PR → main. Запись на сайт — только: 1–2 строки владельцу → «Да» в чате
   сессии 44 → координатору uuid события с «Да» → «можно» → установка автопилотом.
   Любой запуск автопилота, даже только чтение (GSC-REPORT, пробы), — сначала написать координатору и ждать «можно»
   (координатор 27.11: очередь одна).
3. Отчёт владельцу в чате (коротко), подробно — `cloud/seo_daily/ГГГГММДД.md`, копия координатору.

Не повторять сделанное сессиями 12 и 37 (см. cloud/seo_*). Нельзя: кнопки/разделы без утверждения, блок Googlebot,
имя партнёра из США, данные Copart/IAAI, секреты в репозитории, отключать бэкап/откат/проверки. Нагрузка PA ≥85% — тяжёлое
откладывать. Страницы Японии/США и их карта сайта — задачи SEO-USA-PAGES-001, SEO-SITEMAP-JPUS-001, SEO-JAPAN-MODELS-001
(другая сессия), здесь не дублировать.

## SEO-CATALOG-LANGS-001 — каталог в Google на трёх языках
Владелец 27.11 09:57Z (событие f754b347-6574-4415-8853-e23526c2aa11), ответ на «вернуть каталогу украинский»:
«Конечно, 3 языка: украинский, русский и грузинский.»
Сейчас: один адрес katalog.html, язык меняет скрипт; Google индексирует один язык на адрес (Search Central:
«Managing multi-regional and multilingual sites» — отдельный URL на язык + hreflang).
План (одна установка, по образцу KOREA-RU-001):
1. katalog.html — украинский в исходнике; то же в эталоне catalog_design_golden.html (иначе откат при публикации).
2. /video/ru/katalog.html — русская версия из data-ru (как ru/korea.html).
3. /video/ka/katalog.html — грузинская версия из словаря ua-site-languages.js (покрытие ~95%); недостающие ~7 строк
   и ka title/description — перевод на показ владельцу в превью.
4. hreflang uk/ru/ka + x-default на всех трёх; все три в sitemap.xml; ru/ka пересобирает задача ua_card_lang_job (раз в минуту).
Тело, дизайн, машины, кнопки не меняются. Превью → фото владельцу → «Да» → «можно» координатора → установка.
