# Закрытие остановленной попытки публикации галереи

Запуск 36352273461 остановился в backup с LIVE_PLAN_DRIFT. Открытие транзакции, установка, откат и финализация пропущены GitHub Actions. Транзакция осталась PREPARING без backup receipt и без допуска к записи. Проверенный remote.backup сравнивает план до резервирования базы и не изменяет приложение. Поэтому эта попытка не установила галерею и не приостанавливала бота.

Все 22 публичные карточки получили отдельное обновление favicon после предварительной проверки. Новые изменения должны быть сохранены. Повтор старого запуска запрещён.

Этот отдельный маршрут проверяет точные request/run/launch, хеши проверенного контроллера и backup-кода, исходное состояние и официальный результат всех стадий. Он архивирует исходный HALT, transaction и claim, записывает ABORTED_DURING_BACKUP_BEFORE_APPLICATION_WRITE и завершает только эту попытку по существующему соглашению watchdog о терминальных метаданных. Успешная установка или откат не объявляются. Никакие runtime, workflow, разрешения, nonce или ledger не изменяются.

Регистрация маршрута не снимает остановку. Применение — отдельным атомарным коммитом с проверкой родительского main. Затем необходимы свежий предварительный план, новый запрос, Gate B, backup и все обычные проверки.
