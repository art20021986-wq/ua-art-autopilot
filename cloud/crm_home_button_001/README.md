# CRM-HOME-BUTTON — постоянная кнопка «🏠 Главная» в CRM-боте

Задача: `tasks/CRM-HOME-BUTTON-001.md`. Владелец 15.11 выбрал вариант Б (картинка `cloud/photos/30-CRM-HOME-BUTTON.png`).

## Как работает
- `ua_home_button.py` (новый модуль, одна ответственность):
  - после /start бот один раз на чат (до перезапуска бота) присылает строку «🏠 Кнопка «Главная» внизу…»
    с постоянной нижней клавиатурой Telegram из одной кнопки `🏠 Главная` (`is_persistent`, `resize_keyboard`);
  - нажатие кнопки обрабатывается раньше всех (группа -100) и передаётся боту как команда `/start` —
    тот же обработчик и те же сбросы начатого ввода, что у /start; текст кнопки не попадает в поля карточки.
  - только личные чаты; другой текст не трогается.
- `cars_ui.py` — один блок в конце (`edit_cars_ui.py`), по образцу CRM-PAYMENTS-001: подключает модуль;
  сбой подключения только пишется в журнал, прежние обработчики остаются.

## Проверки
- `test_home_button.py` — на настоящей python-telegram-bot 22.8 (как на сервере): /start даёт кнопку один раз,
  кнопка посреди диалога завершает его как /start, перехват сообщений её не видит; в группах не работает.
- `test_deployment.py` — бэкап/установка/откат на временных файлах, правка cars_ui.py.
- Превью на сервере (`deployment_remote.smoke`): python3.10 бота компилирует новый cars_ui.py и проигрывает
  тот же сценарий на его библиотеке, без сети и без данных. Ничего не пишет.
- Установка по образцу `cloud/home_photo_fix_001`: бэкап, пауза бота, запись двух файлов, проверка,
  запуск бота, откат тем же пакетом. Сайт и CRM установка не меняет.
