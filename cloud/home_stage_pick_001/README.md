# HOME-STAGE-PICK-001 — кнопка «Разместить на главную» в карточке CRM

Владелец (2026-11-09): фото машин на главной не меняются; нужна кнопка в карточке
авто, чтобы самому выбирать машины на главную. Ответы: фото — первое (главное) фото
объявления; плитка — того этапа, где сейчас машина (вариант «А», все 4 плитки).

## Почему фото не менялись
В блоке «Автомобілі в наявності та в дорозі» (video/index.html, #stages) у каждой
из 4 плиток (kiev, georgia, sea, korea) «живе фото» одной машины: `<img class="stage-live"
src="/video/stage/UA-XXXX.webp">`. Номер машины прописан в странице; синхронизация CRM
(master_card.obrabotat_obshuyu) только пересобирает кадр для уже стоящего номера.

## Как работает
1. Владелец открывает карточку опубликованной машины → под «Разместить объявление»
   кнопка «🏠 Разместить на главную» (менеджерам и неопубликованным машинам не видна).
2. Этап по статусу CRM: ua_ → «У Києві», ge_ → «У Грузії», sea_ → «На поромі», kr_ → «В Кореї».
3. Кадр из главного фото объявления делает существующее правило
   master_card.podgotovit_vitrinu (cover_photo из CRM или первое фото) → video/stage/<код>.webp.
4. В index.html меняется только src «живого фото» этой плитки; копия страницы до
   изменения — /home/Carix/ua_home_stage/backup/. Всё под существующим publication_fence.
5. Следующая синхронизация CRM сохраняет выбор (она пересобирает кадр для стоящего номера).

| Файл | Задача |

Новых библиотек нет. Пакет по образцу cloud/home_photo_001: превью (сборка из точных
установленных исходников + правка живой главной в памяти по всем 4 плиткам, список
опубликованных машин и их плиток), затем после «да» владельца — бэкап, пауза бота,
запись, проверка, запуск бота, откат тем же пакетом. Установка сайт не меняет.
