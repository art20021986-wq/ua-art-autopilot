Задача: `tasks/CRM-BOT-PROFILE-001.md`. Владелец 15.11: «оформить Telegram красиво… ты больше меня знаешь».

- `ua_bot_profile.py` (новый модуль): через 10 с после запуска бота сверяет с Telegram и ставит, если отличается:
  описание до «Старт» («Внутренняя CRM UA ART: автомобили, клиенты, заказы. Вход — по коду приглашения от
  руководителя.»), строку профиля («Внутренняя CRM UA ART для сотрудников.») и подписи «Меню»
  (`/start — 🏠 Главная`, `/cancel — ✖️ Отменить действие`). Команды при старте ставит `team_bot.post_init`
  (старые подписи) — модуль идёт после него. Обработчики не меняет; сбой только в журнал.
- `cars_ui.py` — один блок в конце (`edit_cars_ui.py`), как CRM-HOME-BUTTON-001.
- Превью: компиляция нового cars_ui.py, модуль на библиотеке бота против подставного бота, чтение текущих
  текстов бота из Telegram (только GET; токен не выводится). Установка — по образцу crm_home_button_001.
