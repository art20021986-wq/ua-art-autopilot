# Что нужно от владельца — 3 шага

1. Claude автоматически подготовил пакет безопасности и он уже синхронизирован в карантин PythonAnywhere. Ничего ещё не запускалось и сайт не менялся.

2. Владелец одобряет ТОЛЬКО точный Gate A манифест (конкретная задача + SHA файлов), чтобы разрешить безопасный запуск: проверка (только чтение), резервная копия и внешняя проверка сайта.

3. Система вернёт один отчёт по безопасности. Если после отчёта потребуется реально что-то изменить на сайте — это отдельный запрос Gate B, который тоже нужно будет одобрить отдельно.
