# Реклама Google — пошаговая инструкция для владельца (телефон)

Правило: один шаг → скриншот Claude → Claude проверяет → следующий шаг. Пароли и коды в чат не присылать.
Денег не тратим до шага 9 (проверочный лист).

## Шаг 1. Профиль в Google Картах (с сотрудником)
Карточка «ТОВ "ЮА АРТ КОМПАНІ"» (4,6, 19 отзывов) создана сотрудником. Сотрудник со своей почты:
business.google.com/locations → «ЮА АРТ КОМПАНІ» → «Пользователи» → «Добавить» → почта владельца → роль «Владелец».
Владельцу приходит письмо → «Принять». Новую карточку НЕ создавать (потеряются отзывы).
Прислать: скриншот business.google.com/locations с карточкой.

## Шаг 2. Рекламный аккаунт (уже есть: 468-074-7874, «In Progress»)
Safari → ads.google.com (если открывается приложение: «aA» → «Запросить веб-сайт для ПК») → аккаунт 468-074-7874.
Если просит создать рекламу — «Перейти в режим эксперта» → «Создать аккаунт без кампании».
Страна Україна, часовой пояс (GMT+02:00) Київ, валюта гривня (UAH) — потом не меняются.
Способ оплаты НЕ добавлять. Прислать: скриншот первого экрана аккаунта.

## Шаг 3. Связать счётчик сайта (GA4) с рекламным аккаунтом
analytics.google.com (режим ПК) → ресурс «UA ART» → «Администратор» (шестерёнка) → «Связи с Google Рекламой» →
«Связать» → выбрать 468-074-7874 → «Далее» → включить «Автоматическая пометка» → «Отправить».
Прислать: скриншот со статусом «Связано».

## Шаг 4. Заявки как конверсии
ads.google.com → «Цели» → «Конверсии» → «Создать действие-конверсию» → «Импорт» → «Google Analytics 4» →
«Веб» → отметить generate_lead и contact → «Импортировать».
Затем: generate_lead — «Основное действие»; contact — «Дополнительное».
Прислать: скриншот списка конверсий.

## Шаг 5. Проверка компании (верификация рекламодателя)
Google сам попросит (обычно после первой кампании): «Организация» → выписка из ЄДР ТОВ + паспорт или ID-карта
представителя; имя совпадает с платёжным профилем. Фото оригинала, цветное, обе стороны. Загружать только в Google Ads.
Прислать: скриншот «Проверка отправлена».

## Шаг 6. Связать профиль Карт (после шага 1)
ads.google.com → «Объявления и ресурсы» → «Ресурсы» → «+» → «Адрес» → выбрать «ЮА АРТ КОМПАНІ».

## Шаг 7. Плашка «Залишити заявку» на Корее — ставит Claude (пакет KOREA-OFFER-001, по очереди координатора)

## Шаг 8. Кампания — создаёт владелец по подсказкам Claude, сохраняем ПРИОСТАНОВЛЕННОЙ
Поиск; цель «Потенциальные клиенты»; без «Контекстно-медийной сети» и без «Поисковых партнёров»; гео: Україна
(«Присутствие: люди, находящиеся в регионе»), корректировка Київ +20%; языки: украинский, русский;
время 08:00–21:00; бюджет 450 грн/день; ставки — «Максимум кликов» с потолком (сумму даст Claude после Планировщика).
Ключевые слова, минус-слова, тексты — из `report.md` (раздел 5). Прислать: скриншоты каждого экрана.

## Шаг 9. Проверочный лист (до оплаты) — вместе с Claude
Тестовые заявки с адреса `…/video/korea.html?gclid=TEST-<дата>`: кнопка «Залишити заявку», кнопка у лота,
форма Kia K5, форма страницы заказа, телефон, WhatsApp, Telegram, Viber. Каждая заявка — в боте CRM с источником,
события видны в GA4 «Реальное время». Менеджер отвечает.

## Шаг 10. Оплата и запуск теста
Способ оплаты (карта ТОВ; НДС 20% если без статуса плательщика) → включить кампанию → 10–14 дней, 400–500 грн/день.
Каждый день первую неделю: скриншот «Поисковые запросы» → Claude даёт минус-слова.
