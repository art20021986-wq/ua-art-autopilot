# CRM-DIAG-MEDIA-PUBLISH-001 — видео диагностики не появляется на сайте

## Причина (пробы CRM-VIDEO-PROBE-20261012-R3/R4/R5, только чтение)
- Audi A6 UA-0020: видео проверки записано в CRM 04:23:55 UTC (`condition_videos` 1,
  `media` diag_video), файл скачан в `video/diag/UA-0020/01.mp4`.
- Страница `UA-0020-diag.html` всё ещё с заглушкой «не добавлены».
- `kadry_diagnostiki` скачивает файлы диагностики сам, раз в 120 с, в отдельном потоке.
  `ua_crm_public_sync` переиздаёт карточку только при изменении строки CRM.
  Карточку переиздали в 04:24:08 — до скачивания; потом CRM не менялась → повторной
  публикации не было. Так может случиться с любой карточкой.

## Исправление
- `ua_diag_files.py` (новый, одна задача): имена файлов диагностики, из которых
  строится страница (как `stranica.kadry_diagnostiki`), без постеров; только имена,
  чтобы перекодирование файла не вызывало повторных публикаций.
- `build_public_sync.py`: в `ua_crm_public_sync.snapshot` к ревизии карточки добавляются
  эти имена (только если файлы есть). Тот же существующий воркер переиздаёт карточку,
  когда файл скачался или удалён. Публикация, проверки и откат — прежние.
- Карточки без файлов диагностики: ревизия не меняется (тест на точном исходнике).
- Только стандартная библиотека. 6 тестов.

## Эффект установки (нужно «да»)
- Один раз переиздадутся карточки, у которых есть файлы диагностики
  (UA-0020 получит видео; остальные с диагностикой — та же страница заново).
- CRM не меняется.
