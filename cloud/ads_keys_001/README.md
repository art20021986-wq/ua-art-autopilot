- `ua_google_ads_auth.py` (новый) — ключи в /home/Carix/google_ads_api.json (права 600, вне папок сайта), ссылка «Разрешить»
  с одноразовой меткой (30 минут), обмен кода на постоянный ключ доступа. Значения не попадают в журналы.
- `ua_google_ads_key.py` (новый, бот CRM) — владелец/управляющий в личном чате присылает одним сообщением токен
  разработчика, идентификатор и секрет клиента (в любом порядке). Обработчик раньше всех (группа −10001, перед ключом
  Telegram −10000): сообщение удаляется, ключи сохраняются, бот присылает ссылку «Разрешить». Ошибочный формат —
  тоже удаляется. Обычные сообщения не трогает.
- `ua_google_ads_oauth_web.py` (новый, сайт) — служебный адрес GET /api/google-ads/oauth: сюда Google возвращает после
  «Разрешить»; короткая страница «Готово ✅», noindex, без кеша. Все остальные адреса сайта идут как раньше.
- `cars_ui.py` — один блок подключения в конце; `ua_order/host.py` — одно изолированное подключение после входа аукциона.
- Установщик — образец `cloud/autosearch_001` (бэкап, пауза бота, замки, откат, перезапуск веб-приложения, живая проверка
  адреса). Превью — модули в интерпретаторе бота, ключи и обмен кода во временной папке (ответ Google подменён).
- Тесты: `test_ads_keys.py` (21), `test_deployment.py` (28).
