# GSC-GROWTH-001 — Google узнаёт о машинах сразу + страница «Авто під замовлення»

Основание: отчёт `cloud/gsc_access_20261020/README.md` (новые карточки не в индексе Google,
украинские запросы «авто під замовлення / підбір авто» на 27–55 месте). Решение владельца: «Да».

| Файл на сервере | Что |
|---|---|
| `ua_google_sitemap.py` (новый) | после изменения карты сайта просит Google перечитать её (Search Console API, служебный аккаунт, ключ на сервере); таймауты 10 с, сбой не мешает публикации |
| `ua_seo_index.py` | вызывает его рядом с IndexNow |
| `ua_seo_landings.py` | новая страница uk `seo/ua/avto-pid-zamovlennia-kyiv.html`, ru `seo/ru/avto-pod-zakaz-kiev.html`: страны (как на главной), примеры из каталога, этапы, 5 вопросов + FAQPage; ссылка на неё с хабов |

Пункт 4 (дубль `podbor.html?strana=…`) не требует правки: у страницы уже есть canonical на чистый адрес.

Установка: бот на паузе, 3 файла, пересборка SEO-страниц и карты сайта (первая отправка в Google и IndexNow),
бот запускается, публичная проверка новых страниц и карты сайта. CRM, карточки, главная не меняются.

Проверки: 32 теста (отправка в Google, вызов только при изменении карты, страница заказа, установка/откат).
