# Критическое ТЗ: распознавание объявления CRM-ботом

## P0-цель

Владелец передаёт данные автомобиля текстом, фотографией/скриншотом,
голосом или изображением-документом. Бот немедленно формирует предпросмотр
только из реально существующих полей формы CRM и показывает кнопку
`✅ Разместить`. Без нажатия владельца карточка и сайт не изменяются.

## Обязательные требования

1. Единственный перечень допустимых полей — `ai_filter.ALLOWED` работающего
   CRM-бота. Запрещено поддерживать параллельный расширенный список.
2. Любой неизвестный ключ удаляется сразу после распознавания и не попадает
   в предпросмотр, черновик, комментарий, журнал, БД или страницу сайта.
3. `summary` и `question` модели не используются для переноса лишних данных.
4. Фото: цель не более 5 секунд, жёсткий ответ пользователю не позднее 7 секунд.
   По тайм-ауту исходник остаётся во входящих, запись в карточку запрещена.
5. Текст: не более 2 секунд; для строк `Поле: значение` используется быстрый
   детерминированный разбор. Голос: полный предел не более 10 секунд.
6. Убрать второй AI-review и автосохранение. Единственная точка записи —
   подтверждение владельца кнопкой `✅ Разместить`.
7. Новая карточка автомобиля допускается только при наличии VIN. Существующий
   VIN не дублируется; заполняются только пустые поля существующей карточки.
8. Фото/скриншот, присланный для распознавания, не добавляется в галерею.
9. Установка не публикует UA-0010, не меняет `crm.db`, страницы UA-0001…UA-0009
   и файлы сайта. UA-0010 размещает только владелец кнопкой после проверки.
10. Изменяемые production-файлы: только `team_bot.py` и новый
    `ai_fast_schema.py`. Перед заменой обязательны точные хеши, резервная копия,
    атомарная запись, компиляция, контроль неизменности БД/сайта и откат.

## Приёмка

- на тестовом изображении Kia K5 распознаются только доступные поля CRM;
- `Киев` и любые иные данные без поля CRM отсутствуют в результате;
- предпросмотр появляется не позднее 7 секунд либо приходит короткий тайм-аут;
- до нажатия `✅ Разместить` количество карточек и страницы не меняются;
- после нажатия сохраняется ровно одна карточка/обновляется карточка того же VIN;
- перезапуск бота подтверждён, компиляция проходит, откат подготовлен.
