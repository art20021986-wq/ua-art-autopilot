# TASK 059 — быстрый мультимодальный ввод в CRM

Патч применяется только к Telegram CRM-боту. Он не создаёт UA-0010 сам,
не изменяет базу CRM и не пересобирает сайт при установке.

## Результат

- текст, фото/скриншот, голос и изображение-документ проходят через один
  закрытый перечень полей — текущий `ai_filter.ALLOWED` рабочего CRM-бота;
- незнакомые поля, подписи, город, продавец и прочие сведения без назначения
  удаляются до показа, журналирования и сохранения;
- фото имеет целевое время 5 секунд и жёсткий пользовательский предел 7 секунд;
- текст имеет предел 2 секунды, голос — 10 секунд;
- медленный второй AI-review и прежнее автосохранение удалены;
- карточка записывается только после нажатия владельцем `✅ Разместить`;
- скриншот-источник не переносится в галерею автомобиля;
- VIN проверяется существующим `ai_filter.store`, поэтому повторный VIN дополняет
  существующую карточку, а не создаёт дубликат.

Установщик меняет только `/home/Carix/team_bot.py` и добавляет
`/home/Carix/ai_fast_schema.py`. Перед заменой создаётся резервная копия;
при любой ошибке выполняется откат. Хеши `crm.db` и страниц сайта проверяются
до и после установки.
