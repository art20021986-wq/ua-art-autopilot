## Фактические условия продолжения

1. Текущий тариф Carix допускает один web app, занятый www.uaart.com.ua.
   Проверенный расчёт второго слота: **$24.50/месяц вместо $21.50**, то есть **+$3/месяц**.
   Остальные параметры сохраняются: 5 000 CPU-секунд, три web workers,
   пять Always-On tasks, 35 GB. Владелец разрешил новый расход ответом
   «Да разрешаю». Однако проверка интерфейса создания web app в 08:00 UTC
   по-прежнему показала лимит одного сайта: финальное подтверждение оплаты
   в PythonAnywhere ещё ожидается. Повторное разрешение владельца не требуется.
2. Для защищённого Preview нужен отдельный HTTPS web app и отдельная настройка
   аутентификации. Существующий Production не используется для эксперимента.
3. Для постоянного чтения управляющего репозитория подготовлен reader с отдельным
   GitHub-доступом **Contents: read только art20021986-wq/ua-art-autopilot**.
   Владелец разрешил этот доступ тем же ответом «Да разрешаю»; создание и
   безопасное подключение ключа ещё не подтверждены. Одноразовый приёмник
   принимает ключ только скрытым вводом через TTY и не активирует reader.
   Существующий серверный API_TOKEN даёт доступ к
   PythonAnywhere и не заменяет GitHub-доступ. Сейчас репозиторий публичный;
   сохранённое owner_decisions предусматривает private target, поэтому постоянный
   процесс не строится на зависимости от публичного доступа.
4. После подключения среды: связать реальные медиа, пройти полный Preview,
   штатно обновить canonical runtime/workflow pins, выполнить разрешённую
   автоматическую публикацию, полный post-deploy и реальный Stage 4 цикл.
   Дополнительное общее утверждение ТЗ или публикации после 100% PASS не нужно.
