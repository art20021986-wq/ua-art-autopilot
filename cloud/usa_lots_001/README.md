# USA-LOTS-001 — машины США (IAAI) на сайте

- Ставится: новый сборщик `usa_auction/` и его задача на сервере `usa_ticker_job.py` (раз в час, первый запуск через пару минут после установки); в общей ленте на главной появляются карточки США (меняются только `korea_auction/ticker.py` и `job.py`).
- Новых страниц нет: `video/usa.html`, `video/korea.html`, `video/japan.html`, японский сборщик и CRM не меняются.
- IAAI читаем только через открытые страницы, под своим честным именем клиента (`UAArtAutopilot/1.0`), бережно: не больше 60 запросов в час, пауза 4 с между запросами; если IAAI отказывает — прогон останавливается.
- Copart не входит: его данные закрыты без входа в аккаунт.
- Откат: убирает задачу США, новые файлы и только то, что она записала (`video/usa/lots.json`, `feed.json`, `gallery/`, `lots/`, `usa_auction_data/`); прежние `ticker.py` и `job.py` возвращаются.
- Установка — через `make_release.py` (превью, затем установка после «да» владельца).
