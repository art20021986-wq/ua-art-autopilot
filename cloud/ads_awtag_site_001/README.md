«Заявка з сайту (тег Google Ads)» и дал адрес конверсии `AW-18537441937/fvkWCIT9vsAdEJHVq4dF`.
Ждёт «Да» владельца и очереди координатора. Пакет НЕ запущен.

## Что меняется
| Где | Что |
|---|---|
| `ua_google_tag.py` (сейчас V1, хеш f5f0a304, GA4-TAG-001) | V2: GA4 как было + `gtag('config','AW-18537441937')`; каждое событие `generate_lead` (большая форма, передача в Telegram, короткая форма quick-lead.js) отправляет одну конверсию Google Ads. `apply()` заменяет старый блок, поэтому все писатели страниц дальше пишут V2 |
| все страницы `video/**`, `site/**` с блоком тега | блок V1 заменяется на V2; больше на странице ничего не меняется |

В блок добавляются только эти строки (после `gtag('config','G-6SRBQK6GY4');`):

```
gtag('config','AW-18537441937');
(function(){var base=gtag;gtag=function(){base.apply(this,arguments);if(arguments[0]==='event'&&arguments[1]==='generate_lead')base('event','conversion',{send_to:'AW-18537441937/fvkWCIT9vsAdEJHVq4dF'});};})();
```

Без расширенных конверсий и без данных клиента: текст политики конфиденциальности не меняется. Новых адресов на
странице нет (тот же загрузчик googletagmanager.com). Метки блока остаются `<!--UA-GTAG-V1-->…<!--/UA-GTAG-V1-->`:
по ним сторож дизайна каталога и проверки страниц вырезают блок — их менять не нужно.

## Безопасность
Бэкап CRM, пауза бота, замки записи, на время установки держатся замки корейской, японской и американской задач
(они в это время ничего не пишут), откат байт в байт, проверки здоровья и сторож транзакций — как в LOGO-CARD-001.
Если писатель после установки перепишет страницу, у неё уже будет V2; откат такой страницы возвращает блок V1, а
остальное оставляет как записал писатель.

## Проверки

  Корея): V1 → V2 — только вставка этих строк, откат точный, повтор ничего не меняет, страница без тега получает V2
  на месте V1, сторож каталога видит ту же оболочку, нет данных клиента и новых адресов.
- `test_google_tag.py` (Node): одна конверсия на каждый `generate_lead` (форма, Telegram, короткая форма
  из живого quick-lead.js), ни одной — на клик по телефону и при загрузке; GA4 и Ads настроены.
- `test_deployment.py`: установщик (бэкап, пауза, замки, откат, сбои, переписанные страницы), превью на копии сервера,
  публичные проверки.
- Превью на сервере: найти все страницы с блоком, каждая отличается только блоком, новый модуль пишет то же.
- После установки: главная, каталог, подбор, Корея — блок V2 один раз, V1 нет.
