## R1 (28.11, run 46154739330) и что исправлено в R2
R1 откатилась: проверка после установки нашла `video/seo/ru/audi-a6-koreya-kiev.html` переписанной без V2. Причина
(по коду): пауза бота считала «stopping» остановкой (`state != 'running'`), а проверка процессов смотрит только свой
сервер — старый процесс бота жил дальше со старым модулем в памяти. Его минутная задача `ua_card_lang_job` (после
пересборки версий карточек) вызывает `ua_seo_index.refresh` — единственный писатель SEO-страниц — и после снятия замков
переписала их со старым блоком V1 (первая по порядку — audi-a6). В откате то же: бот, запущенный после установки (V2 в
памяти), пережил паузу и в 14:51:40 переписал все 32 SEO-страницы с V2 уже после возврата файлов; модуль и остальные
страницы — V1. Тот же урок уже был в PUBLISH-VIDEO-LATENCY-002.

R2 (`ADS-AWTAG-SITE-PREFLIGHT-20261128-R2` / `ADS-AWTAG-SITE-INSTALL-20261128-R2`), объём тот же (только блок V1 → V2):
- пауза бота ждёт явного «stopped» (как PUBLISH-VIDEO-LATENCY-003); бот запускается только после замены файлов;
- под замками один управляемый пересчёт SEO-страниц установленными модулями (как LOGO-SITE-001), второй пересчёт
  ничего не меняет, страницы сверяются байт в байт до снятия замков;
- проверка после запуска бота читает страницы под замками писателей страниц (сторож публикаций, воркер CRM, аукционы);
- откат: сначала модули, потом страницы; каждая страница уходит с V1 (и SEO-страницы, уже V2 с 28.11);
- страница, уже несущая V2 (32 SEO-страницы с 28.11), в плане остаётся как есть; публичная проверка + SEO-страница.

## Что меняется
| Где | Что |
|---|---|
| `ua_google_tag.py` (сейчас V1, хеш f5f0a304, GA4-TAG-001) | V2: GA4 как было + `gtag('config','AW-18537441937')`; каждое событие `generate_lead` (большая форма, передача в Telegram, короткая форма quick-lead.js) отправляет одну конверсию Google Ads. `apply()` заменяет старый блок, поэтому все писатели страниц дальше пишут V2 |
| все страницы `video/**`, `site/**` с блоком тега | блок V1 заменяется на V2; больше на странице ничего не меняется |

В блок добавляются только эти строки (после `gtag('config','G-6SRBQK6GY4');`):

```
gtag('config','AW-18537441937');
(function(){var base=gtag;gtag=function(){base.apply(this,arguments);if(arguments[0]==='event'&&arguments[1]==='generate_lead')base('event','conversion',{send_to:'AW-18537441937/fvkWCIT9vsAdEJHVq4dF'});};})();
```

Без расширенных конверсий и без данных клиента: текст политики конфиденциальности не меняется. Новых адресов на
странице нет (тот же загрузчик googletagmanager.com). Метки блока остаются `<!--UA-GTAG-V1-->…<!--/UA-GTAG-V1-->`:
по ним сторож дизайна каталога и проверки страниц вырезают блок — их менять не нужно.

## Безопасность
Бэкап CRM, пауза бота, замки записи, на время установки держатся замки корейской, японской и американской задач
(они в это время ничего не пишут), откат байт в байт, проверки здоровья и сторож транзакций — как в LOGO-CARD-001.
Если писатель после установки перепишет страницу, у неё уже будет V2; откат такой страницы возвращает блок V1, а
остальное оставляет как записал писатель.
