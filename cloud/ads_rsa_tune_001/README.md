# ADS-RSA-TUNE — замена двух заголовков в объявлениях Кореи

Владелец «Да» 28.11 13:44Z. Кампания «Пошук — Україна — Корея (UA ART)» (прежнее имя «Пошук — Київ — Корея»),
все адаптивные поисковые объявления (включённые и на паузе):

- укр.: «Передоплата в ціні авто» → «Авто з Кореї під ключ Київ»; «Етап доставки онлайн» → «Купити авто з Кореї»;
- рус.: «Предоплата в цене авто» → «Авто из Кореи под ключ Киев»; «Этап доставки онлайн» → «Купить авто из Кореи».

Если новый заголовок уже есть в объявлении — старый просто убирается (без повторов). Закрепление заголовка
сохраняется. Если после замены заголовков меньше 3 (или больше 15, или длиннее 30 знаков) — объявление не трогаем,
оно в отчёте как SKIPPED.

Как работает: один запуск в временной задаче PythonAnywhere — чтение объявлений, один запрос в Google Ads
(по одной правке на объявление, ~70 правок, частичные отказы допускаются), повторное чтение. Бюджет, ставки,
ключи, описания, ссылки не отправляются и сверяются до/после. Повторный запуск ничего не меняет.

Отчёт `cloud/ads_rsa_tune_001/<дата>.json`: по каждому объявлению — было, стало, отказы Google с темой политики.

Новые объявления ночной загрузки (`cloud/ads_bulk_001/plan.py`) уже с новыми заголовками.

Запуск (после слияния и «можно» координатора): `python3 cloud/ads_rsa_tune_001/make_request.py launch 20261128`.
