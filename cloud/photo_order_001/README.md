# PHOTO-ORDER-001 — фото в карточке в порядке отправки, первое — главное

Владелец 19.11: «загружал фотографии в последовательности 1, 2, 3… первое главное, остальные в порядковом номере».

Причина (проба PHOTO-ADD-PROBE-20261119-R5): очередь фото сохраняет их в порядке прихода в бот; фото двух альбомов
одной загрузки приходят вперемешку (у UA-0011 — «через одно»). Telegram нумерует сообщения чата в порядке отправки,
и очередь этот номер уже хранит.

- `cars_ui.py` (`edit_cars_ui.py`): после каждого прохода очереди у сохранённого фото записываются отправитель и номер
  сообщения, фото одного отправителя ставятся по номеру; прежние фото без номера остаются на своих местах; фото
  владельца и менеджера (разные чаты) упорядочиваются каждый в своих местах. Сбой — только в журнал.
- Тесты: `test_photo_order.py` (живой код очереди после PHOTO-ADD-001, `fixtures/cars_ui_photos.py`): перемешанные
  альбомы — до правки порядок прихода, после — порядок отправки; поздний кадр встаёт на своё место.
- Установка — как photo_add_001 (бэкап, пауза бота, замки, откат).
