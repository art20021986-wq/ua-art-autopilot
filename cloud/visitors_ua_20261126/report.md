## Что есть и чего не хватает для «по каждому посетителю»
- Свой счётчик (analytics.db): 1 314 анонимных посетителей, 1 897 визитов, 9 666 действий — маршрут, клики, глубина
  чтения есть; **страны нет**, **реклама видна как «прямой»** (gclid не читается), сотрудников отличить нельзя.
- GA4: страна, город, устройство, источник есть, но по отдельному человеку Data API не даёт (только группы).

## Было → станет (на утверждение)
1. Счётчик пишет часовой пояс и язык браузера (без IP и личных данных) → фильтр «Украина» (Europe/Kyiv) и отсев
   роботов дата-центров (их пояс не Киев).
2. Счётчик различает «Реклама Google» (по gclid) и показывает группу объявлений/страницу входа.
3. «Не считать меня»: одна служебная ссылка для владельца и Олега — устройство помечается и выпадает из отчёта.
4. Отчёт «Посетители из Украины»: итог + по каждому: откуда, город (из GA4 — по дню и странице), устройство,
   маршрут страниц со временем, клики (карточки, кнопки связи, форма), итог визита.
Формат — на выбор владельца: сообщение раз в день в бот CRM; кнопка в «Аналитике» бота; страница.
Альтернатива (официально у Google, бесплатно в пределах лимита): выгрузка GA4 → BigQuery — каждое событие с анонимным
ID и страной; требует связать GA4 с BigQuery в настройках (один раз, владелец).
