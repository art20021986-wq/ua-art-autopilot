## Исправлена причина отсутствующего nonce в изолированном кандидате

`prepare_nonce_fix.py` создаёт текст патча двух существующих workflow.
Он не изменяет активные workflow, runtime manifest, режим, HALT, старые approvals,
claims, launch, nonce и transaction. Готовый патч — `nonce-workspace.patch`.
Его нельзя применять отдельно от штатной регистрации проверенного runtime.

В исходных workflow временная рабочая копия отката получает пять записей.
Файл резервирования nonce создан после исходного commit установки, поэтому
его нет в этой копии. Проверка ledger закономерно останавливается до запуска
контроллера отката. Патч добавляет шестую запись, проверяет её точный путь
и SHA из ledger и сохраняет все проверки исходного валидатора. Некорректная
или отсутствующая запись отклоняется до первого копирования. Пути назначения
с symlink также отклоняются до записи.

10 тестов выполняют настоящие встроенные Python-блоки обоих workflow во
временных каталогах: исходная ошибка, перенос точных шести записей, отсутствующий
или изменённый nonce, другой nonce, выход за область путей, symlink источника
и назначения, дрейф source commit и workflow. Все прошли.

`rehearse.py` дополнительно извлекает фактический commit неудачной установки
`9fd580ca61c67dfb944bc4826fd1f18459ffba0b` во временные каталоги, копирует
текущие записи транзакции и запускает **неизменённый закреплённый валидатор**:

| Рабочая копия | critical workflow | watchdog workflow |
|---|---|---|
| Исходная | `AUTOSTART_NONCE_RESERVATION_MISSING` | `AUTOSTART_NONCE_RESERVATION_MISSING` |
| С кандидатом исправления | Ledger PASS | Ledger PASS |
| Статус транзакции после проверки | `ROLLING_BACK` | `ROLLING_BACK` |

Протокол — `rehearsal.json`. Это проверка сборки рабочей копии, а не выполненный
откат, не live Gate B и не разрешение повторно использовать одноразовую попытку.
Запросы к PythonAnywhere, доступ к секретам и запуск rollback здесь отсутствуют.
