# Две папки автомобилей — подготовленный кандидат

**Статус: PARTIAL — локальный модуль готов, в бот не установлен.**

`folders.py` строит две папки и списки из существующих карточек по подтверждённому `published`. Количество динамическое, порядок карточек сохранён. `listing()` использует переданный существующий формат подписи и callback `car_open:<id>`. Данные не копируются в новые карточки и не изменяются. Неизвестные флаги и дубли ID отклоняются, не превращаясь в неверные счётчики.

Команда проверки:

```bash
python3 -m unittest discover -s cloud/crm_catalog_folders_001 -p 'test_*.py' -v
```

Результат: **7 тестов PASS**. Проверены состав и неизменность данных, автоматический пересчёт после имитируемой успешной публикации/снятия, независимость от этапов, неизменность при отсутствии успешной фиксации, отбрасывание неоднозначных данных, пагинация, пустые папки и callbacks.

Не проверены и не заявляются: текущие 19 опубликованных карточек, действующий Telegram-обработчик, реальные права сотрудников, реальная публикация/снятие, возврат из карточки, установка на сервере. Модуль не содержит встроенной авторизации: её обязан сохранить существующий обработчик до чтения снимка и построения представления. Полная инструкция завершения: `tasks/task_122.md`.

Независимая проверка модуля не выявила ошибок разбиения и пагинации. Обнаружен блокер интеграции: в старом `patcher_v2.py` published ставится до выполнения публикации. Поэтому действующий источник завершённого состояния ещё нужно установить; простой вызов модуля с сырой строкой такой базы неприемлем. Возврат из карточки также требует действующего адаптера. Размер страницы задаётся адаптером по существующему интерфейсу, нового лимита в модуле нет.

Доступ к репозиторию подтверждён. На main обнаружен `EMERGENCY_HALT`. Актуального `/home/Carix/cars_ui.py` в просмотренных материалах нет. Поиск доступного подключения PythonAnywhere не дал результата. Чтение каталога через веб-инструмент было недоступно; это не является доказательством неработоспособности сайта.

В этом изменении нет launch-маркера, workflow, снятия HALT или команд сервера. Рабочий бот и сайт не изменены. Повторного согласования самого разделения на папки не требуется; для дальнейшего исполнения нужен актуальный исходник и разрешённый рабочий доступ к серверу.
