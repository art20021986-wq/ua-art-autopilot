## Изменение

Существующие кнопки, включая дополнительную спецификацию, и цепочка register сохраняются.

build_installer.py создаёт автономный crm_folders_install_20260910.py. Он проверяет точный SHA256 исходника, структуру функций, компиляцию, реальный каталог и CRM через SQLite mode=ro. Конкурирующая замена core не затирается. --rollback <backup> возвращает исходный код только при точном совпадении ожидаемых хешей.
