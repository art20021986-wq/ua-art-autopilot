## Выполненная установка

Из проверенной копии этой версии репозитория на PythonAnywhere:

```sh
python3.10 cloud/order_eight_countries_001/update_web.py apply --backup /home/Carix/order_ui_cleanup_20260927_78cebee
```

`update_web.py` проверяет SHA256 всех четырёх текущих файлов до записи,
создаёт новую приватную резервную копию, публикует ресурсы до HTML,
проверяет результат и возвращает `INSTALLED_STATIC_UI`.
Не запускает и не перезагружает процессы. При несовпадении исходников
нужна проверка различий; автоматического принудительного перезаписывания нет.

Откат использует ту же резервную копию и отказывается затирать поздние правки:

```sh
python3.10 cloud/order_eight_countries_001/update_web.py rollback --backup /home/Carix/order_ui_cleanup_20260927_78cebee
```

Установка и просмотр рабочего сайта выполнены. Процессы ботов и веб-приложения
не перезапускались: обновлены только четыре статических файла интерфейса.
