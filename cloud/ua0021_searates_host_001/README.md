# UA0021-SEARATES-HOST-001 — карточка UA-0021 не переиздаётся

## Причина (SEO-GROWTH-VERIFY-20261012, только чтение)
- По правилу владельца (28.09) у контейнеров не ONE кнопка «Отследить контейнер» ведёт на
  SeaRates (CARRIER-TRACKING-INSTALL-20260928). На UA-0021 это `www.searates.com`.
- Более ранняя защита TASK115 в `ua_additional_spec.inject_public_spec` пропускает только
  внешние сайты из `_UA115_APPROVED_HOSTS`; SeaRates там нет → любая сборка UA-0021 падает
  `UA115_UNAPPROVED_EXTERNAL_HOST`, работник повторяет попытку до 15 минут.

## Исправление
Одна строка списка разрешённых сайтов получает `www.searates.com` (сборщик сверяет хэш
установленного файла и заменяет ровно эту строку). Остальные проверки TASK115 — без изменений.

## Эффект установки (владелец: «Да», 2026-10-12)
Код одного файла; бот на паузе, страницы и CRM при установке не меняются, откат автоматический.
После установки работник переиздаёт UA-0021 (SEO-заголовок, разметка, ссылки), попытки прекращаются.

## Проверки
24 теста: ровно одна изменённая строка; настоящая функция проверки на настоящей странице UA-0021
(до — отказ из-за SeaRates, после — пропуск); отказ при любом другом исходнике; откат установки.
