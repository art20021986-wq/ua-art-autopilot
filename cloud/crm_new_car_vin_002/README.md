# NEW-CAR-VIN-SPEC — основные поля новой карточки по VIN

Задача: `tasks/NEW-CAR-VIN-SPEC.md`. Макет: `cloud/crm_new_car_vin_spec_mockup.png`.

Модули (каждый — одна ответственность):
- `ua_vin_decode.py` (новый) — VIN → модель, год, объём, топливо, КПП, привод из официальной базы NHTSA vPIC
  (бесплатно, без ключа). Берётся только чистая расшифровка (ErrorCode 0); слова vPIC сводятся к кодам словаря CRM
  и нормализуются установленным ai_fast_schema. Неизвестное — пропускается. Марку не берёт (её даёт vin_brand).
- `ua_new_car_bot.py` (замена версии NEW-CAR-VIN-001) — «🔎 Расшифровываю VIN…», расшифровка вне цикла бота,
  карточка через установленный photo_card. Сбой расшифровки — карточка как раньше (марка + VIN).
- `candidate_builder.py`, `deployment_*`, `make_release.py` — установка по образцу `cloud/crm_new_car_vin_001`.

Проверка на сервере (проба): расшифровка VIN владельца `WDDZF4KB1KA596783` одним запросом к vPIC.
Тесты: `test_vin_decode.py` (ответы vPIC, словарь CRM, бот на точных серверных модулях), `test_deployment.py`.
UA-0025 дозаполняется отдельной установкой (запись в CRM).
