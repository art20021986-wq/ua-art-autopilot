# SeaRates: один переход из карточки

Запрос владельца 28.09.2026: бейдж номера слева, «Отследить контейнер» справа,
один SeaRates, автоматическая передача номера, без видимого URL, выбора
сервиса, копирования и вставки. Существующие и будущие карточки.

Кандидат меняет только два прикладных модуля. Используется обычная HTML-ссылка
на `https://www.searates.com/container/tracking/?number=FBLU0045137&sealine=AUTO`.
Номер сохраняется полностью, параметры кодируются стандартным `urlencode`.
JavaScript блока удалён. Маркеры прежней версии сохранены для точного обновления
существующих карточек; три установленных генератора уже вызывают этот модуль.

## Проверка внешнего результата — BLOCKED

При проверке в браузере без входа в SeaRates номер FBLU0045137 автоматически
создал запрос. Вместо маршрута SeaRates показал `Daily request limit reached`,
`Please register or login to continue using our Container Tracking` и
`API key limit reached`. Подстановка и запуск поиска подтверждены;
местоположение груза и работа для посетителя без входа не подтверждены.

Ссылка с номером сама по себе не снимает лимиты SeaRates. Для продолжения
нужен проверяемый доступ к результату: например, штатная ссылка «Поделиться»
из SeaRates, открывающаяся клиенту, либо авторизованная интеграция. Платные
подписки, новые аккаунты и API-интеграция этим кандидатом не подключаются.

Проверки кандидата: 34 теста PASS; 22 сохранённые реальные карточки преобразуются
идемпотентно, девять получают ровно одну ссылку, все байты за пределами блока
отслеживания сохранены. Это подготовка к изменению, не приёмка внешнего результата.

## Состояние публикации

**Не установлено.** В рабочем сайте остаётся ранее принятая версия с несколькими
источниками. `validation.json`, `live_verification.json`, план и production receipt
описывают именно ту прежнюю установку. Новые наблюдения кандидата находятся в
`searates_candidate_validation.json`. Старые SHA, Gate B и launch marker не
подходят для этого кандидата; перед публикацией нужен свежий штатный план
с проверкой актуального состояния сайта и отдельной приёмкой SeaRates.
