# Отслеживание отправки в карточках

Задача владельца 27.09.2026: несколько источников отслеживания из блока доставки
на всех существующих и будущих карточках, без новых зависимостей и фонового опроса.

Причина ограничения: три генератора показывали ссылку только для значений ONEY.
Свежая проверка CRM также выявила физический номер контейнера другого формата;
подставлять его в поиск ONE или удалять первые четыре символа нельзя.

`ua_tracking_links.py` нормализует явно введённый номер и формирует ссылки.
`ua_tracking_widget.py` выводит доступный с клавиатуры HTML details/summary и
копирование номера с обработкой отказа браузера. RU/UA/GE используют существующий
переключатель языка. Два этих файла — единственные новые прикладные модули.

Track-Trace открывает нужную форму с номером. SeaRates и ShipsGo открывают поиск;
для них предлагается скопировать номер. Существующая ссылка ONE для коносамента
сохранена. Нет API, iframe, фоновых запросов, новых библиотек или подписок.
Сервисы могут требовать вход и не гарантируют данные по каждой отправке.
Префикс физического контейнера не считается доказательством перевозчика.

`build_candidate.py` меняет только блок номера/ссылки в трёх генераторах по точным
SHA. `card_tracking.py` обновляет только соответствующий участок существующих
страниц. CRM, фотографии, цены, этапы и даты доставки не изменяются.

Установка — только штатные main Actions. Пакет использует уже испытанный цикл
oneclick release с отдельными именами задач и файлов. План содержит точные хеши
исходников и HTML; новая правка владельца требует нового плана. Бэкап, журнал,
остановка/возобновление только установленного бота, блокировки, откат и проверка
обычных публичных URL сохранены. Перед установкой также сверяются состав
существующих карточек и использованные номера отправок; поздняя правка требует
свежего плана и не перезаписывается. Откат не перезаписывает поздние сторонние правки.
Превью не меняет приложение или CRM и ограничено 20 CPU-секундами.

Проверки: 34 теста, включая сбой записи, прерванную установку, повреждение бэкапа,
сохранение очереди и новых правок CRM, отказ при устаревшем публичном HTML.
19 локальных копий настоящих карточек: преобразование идемпотентно, всё за пределами
блока доставки совпадает побайтно. Это не свидетельство установки на рабочем сайте.

Источники, проверенные 27.09.2026:

- https://track-trace.com/container — 171 компания; в браузере проверен номер в `#CSQU3054383`.
- https://track-trace.com/bol — отдельный поиск B/L; проверен `#ONEYTEST123456`.
- https://www.searates.com/container/tracking/ — альтернативный поиск.
- https://shipsgo.com/ocean — контейнер, B/L, booking, 160+ перевозчиков; возможен вход/лимит.
- https://www.bic-code.org/identification-number/ — структура номера и код владельца контейнера.
- https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/details
- https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText

Полный автоматический поиск отправки на всех внешних платформах не заявлен.
Для Track-Trace подстановка номера проверена; результат конкретного рейса зависит
от перевозчика и опубликованных им данных.
