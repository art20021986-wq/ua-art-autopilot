# Единая кнопка отслеживания контейнера

Уточнение владельца от 28.09.2026: номера ONEY открывают ONE, остальные номера —
SeaRates. На UA-0021 номер FBLU0045137 открывается через SeaRates. На всех карточках
номер находится слева, одна заметная золотая кнопка «Отследить контейнер» — справа.
Список сервисов, копирование и ручная вставка удалены; сырой URL не показывается.

`ua_tracking_links.py` нормализует ввод и выбирает одну ссылку. Для явного B/L
ONE (`ONEY…`) используется прежний официальный адрес с `trakNoParam`: только
в запросе ONE удаляется служебный префикс ONEY, как требует его форма поиска.
Видимый номер сохраняется полностью. Все остальные номера передаются целиком
в SeaRates через `number` и `sealine=AUTO`. Префикс владельца физического
контейнера сам по себе не считается доказательством перевозчика.

`ua_tracking_widget.py` отвечает за общий HTML/CSS: обычная ссылка, состояния
наведения и клавиатурного фокуса, область нажатия не меньше 44 px, RU/UK/KA.
Новые зависимости, API-ключи, iframe и JavaScript для перехода не добавлены.
При отсутствии номера показано сообщение, а ссылка на чужую отправку не создаётся.

В этом уточнении изменён один прикладной модуль выбора сервиса. Виджет и интеграции
трёх генераторов защищены от изменения; новые карточки используют то же правило.
Миграция обновляет только блоки отслеживания на основных и старых сохранённых
адресах. Фото, характеристики, цены, этапы, очередь публикаций и CRM сохранены.

Установлено штатным запуском 36384396069, задача `CARRIER-TRACKING-INSTALL-20260928`.
Свежая проверка сервера, Gate A/B, резервная копия, готовность отката и контроль
изменения исходников/карточек/номеров сохранены. Receipt подтверждает FINISHED,
production/live verification PASS, 46 публичных проверок и работающую CRM.
38 тестов прошли. Независимо проверены 44 адреса 22 машин: 16 ссылок ONE для
восьми машин, две ссылки SeaRates для UA-0021; на остальных номера отсутствуют.
Результаты записаны в `carrier_routing_live_verification.json`.

В браузере ONE автоматически нашёл оба действующих B/L: SELGB4471700 и
SELGF1046602. Второй проверен настоящим нажатием из опубликованной UA-0005,
без ручного ввода номера и дополнительного нажатия поиска.
Реальное нажатие на UA-0021 передало FBLU0045137 в SeaRates и запустило поиск;
SeaRates показал гостевой лимит и предложение войти. Геолокация этой отправки
не подтверждена. Установка правила перехода не означает обход доступа сервиса.
