# TELEGRAM-KEY-BOT — ключ Telegram API владелец присылает боту CRM

Владелец (через координатора 19.11): «Да, делай бот ключа через бот CRM» — вставка в редактор PythonAnywhere на iPhone
не работает. Ключ нужен для VIDEO-LIMIT-001 (свой сервер Telegram Bot API).

- `ua_telegram_key.py` (новый): только владелец CRM, только личный чат; сообщение «api_id api_hash» (цифры, пробел или
  перенос строки, 32 hex). Обработчик в группе −10000 — раньше всех (самая ранняя живая группа −100), останавливает
  дальнейшую обработку: в inbox, crm.db, ИИ-разбор и журналы ключ не попадает. Бот удаляет сообщение, пишет
  /home/Carix/telegram_api.txt (2 строки, права 600, атомарно), отвечает «Ключ сохранён ✅». Похожее на ключ, но
  неверное — тоже удаляется, ответ «Формат не тот: цифры, пробел, 32 знака», ничего не пишется. Значения не логируются.
- `cars_ui.py` — один блок в конце (подключение), как CRM-BOT-PROFILE-001.
- Тесты: `test_telegram_key.py`, `test_deployment.py`. Превью: обработчик на библиотеке бота с подставными сообщениями
  и временным файлом; проверка, что ни один живой модуль не ставит обработчик в группу ниже ключевой.
