# LOGO-001 — сайт: новый логотип C и кнопки «Головна» / «Назад» в шапке

Владелец 28.11 («Да», через координатора): логотип C (`cloud/logo_001/c_badge.svg`) вместо квадрата «UA» в шапке всех
страниц; под логотипом две кнопки «⌂ Головна» и «‹ Назад» вместо подписи «← На головну» (макет
`cloud/header_nav_001/header_nav_final.png`). Пакет НЕ запущен.

## Что меняется (только шапка; тексты, ссылки, фото, переключатель языка, favicon и данные CRM — нет)
| Модуль | Что делает |
|---|---|
| `ua_logo_c.py` (новый) | щит «UA» + «ART» (SVG внутри стиля) на месте квадрата «UA» в обеих шапках (`a.brand .brand-mark`, `.shapka .logo .znak`); без золотого кольца; название компании по центру логотипа |
| `ua_header_nav.py` (новый) | кнопки «Головна» / «Назад» перед RU/UA/GE (на телефоне — в одном ряду с ним); золотая рамка, высота 30 px, зона нажатия 44 px; подписи uk/ru/ka по языку страницы; «Назад» — шаг назад, если пришли со страницы uaart.com.ua, иначе главная; на главной кнопок нет |
| `ua_brand_home.py` (замена) | его блок в `<head>` теперь несёт логотип и стиль кнопок (кольцо и подпись убраны), он же вставляет кнопки |

Подключение: `ua_brand_home` уже вызывают все генераторы страниц (`site_ge_inject.inject_html` — карточки, каталог,
главная, заказ, Корея/Япония/США; `ua_seo_index` — SEO-страницы), поэтому цепочки не правятся. `SEO_REVISION` в
`ua_seo_metadata.py` = `LOGO-001` — CRM один раз пересоберёт карточки; SEO-страницы пересоберёт обновление при установке;
эталон каталога и статичные страницы (index, katalog, podbor, info, privacy, korea, ru/korea, japan, usa) — сразу.

## Запуск (после «можно» координатора)
1. Превью: заявка `tasks/requests/LOGO-PREFLIGHT-20261128.json` уже в пакете; запуск —
   `python3 cloud/logo_site_001/make_release.py launch LOGO-PREFLIGHT-20261128` (файл запуска создавать прямо перед слиянием).
2. После превью и «да» владельца: `python3 cloud/logo_site_001/make_release.py install` → `LOGO-INSTALL-20261128`.
Порядок: после установки SEO-PRICE (она сверяет ua_seo_metadata.py по хешу; этот пакет его не сверяет и поменяет).
