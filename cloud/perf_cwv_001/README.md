## Причины

1. **Главная, CLS 0,297.** Сдвигается `section.hero` («Авто під замовлення»). Над ним пустой
   `<div id="ua-korea-ticker">` (с `:empty{display:none}`), который скрипт заполняет после
   загрузки `/video/korea/ticker.html` (300 КБ, 14 КБ gzip). Блок вырастает 0 → 494 px (телефон),
   426 px (≥768 px) и сталкивает всё ниже. LCP — заголовок h2 блока аукционов (текст), ок.
2. **Карточки, CLS 0,21–0,32.** Сдвигается `section.um-gallery`, потому что над ней растёт шапка
   (`.shapka`), воспроизводится всегда (Playwright, медленная сеть):
   - 191 → 220 px: стиль `.shapka .logo > div:not(.znak)::after` («← На головну») стоит в конце
     `<body>` (после галереи) и применяется поздно;
   - 220 → 272 px: `ua-site-languages.js` (defer) вставляет в шапку переключатель «RU UA GE»
     и меняет текст страницы с русского на украинский.
   Галерея сама размер резервирует (`.um-stage{aspect-ratio:4/3}`), главное фото уже
   `loading=eager fetchpriority=high`.
3. **Каталог, LCP 4,2–4,4 с.** Элемент LCP — фото первой карточки (`UA-0001/001.jpg`), у него
   `loading="lazy"` и нет `fetchpriority="high"` (Lighthouse: «LCP resources shouldn't use
   loading=lazy»). Все 18 фото — полноразмерные JPEG (до 1280 px, 270 КБ при показе 378 px),
   нет srcset/sizes и WebP; картинки ~1,07 МБ из 1,25 МБ страницы.
4. **Главное фото карточки.** `m/` у части машин не уменьшено: UA-0011 `m/001.jpg` 960×1280,
   223 КБ (у UA-0023 — 640×330, 39 КБ). WebP нет ни для одного фото.
5. **TTFB каталога.** Страница — готовый статический файл (Last-Modified, gzip включён,
   `Cache-Control: no-cache, must-revalidate`). Ответ сервера 0,05–0,36 с в Lighthouse,
   0,1–0,5 с curl (8 запросов). 2,48 с у владельца — разовый всплеск хостинга; на сайте
   менять нечего, повторить замер после правок.
6. **Блокирующие стили.** `ua-v203.css` 15 КБ — ~200 мс на главной/каталоге. Шрифты внешние
   не грузятся. Малый эффект.
7. **Прочее (не в задаче, только предложения).** `ua-site-languages.js` — 140 КБ gzip
   (693 КБ) на каждой странице; на карточках синхронный `telegram-web-app.js`;
   `quick-lead.css` подключён внутри `<body>`; фото/css отдаются с `no-cache`.

## План правок (по пользе)

1. Главная: зарезервировать место под блок лотов (`#ua-korea-ticker{min-height:…}` по
   фактической высоте, без `:empty{display:none}` до загрузки) → CLS ≈ 0.
2. Карточки: стиль «← На головну» — в `<head>`; место под переключатель языка в шапке
   зарезервировать заранее (тот же размер) → CLS ≈ 0. Содержимое карточек не меняется.
3. Каталог: первым 1–2 фото — `loading="eager" fetchpriority="high"`, остальным lazy;
   `width/height` у img → LCP ожидаемо ≤ 2,5 с.
4. Фото: на сервере Pillow делает WebP 480/960 px рядом с JPEG (JPEG остаются), в каталоге и
   главном фото карточки — `<picture>`/`srcset`+`sizes` → вес фото каталога в ~3–5 раз меньше.
5. После установки — повторный замер 3×5 страниц.
