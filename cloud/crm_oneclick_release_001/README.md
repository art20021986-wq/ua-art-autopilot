# Установка исправления публикации в одно нажатие

Команда владельца: «Убери блоки и установи», 27.09.2026. Основное ТЗ:
`tasks/UA-ART-CRM-ONECLICK-PUBLISH-001.md`. Дополнительное подтверждение не требуется.

Этот пакет устанавливает ровно четыре ранее проверенных файла: cars_ui.py,
publikaciya.py, ua_crm_public_sync.py и новый ua_publish_requests.py. Полные
исходники с рабочего сервера остаются в закрытом рабочем каталоге. Здесь находятся
только преобразования с точными входными и выходными SHA. Копии трёх сборщиков
помещены в один пакет для обязательной проверки всей цепочки исполняемых файлов.
Итоговые SHA совпадают с crm_oneclick_publish_001/candidate_manifest.json.

Проверочный запуск использует штатный main Actions и временное задание, которое
только собирает пакет в закрытом inbox и измеряет место. Он не меняет приложение,
базу, страницы и состояние бота. Пересборка каталога не выполняется; CPU ограничен
20 секундами. Локальная сборка точных рабочих исходников заняла 0.232 CPU-секунды.
На сервере время измеряется отдельно, поскольку действует ограничение CPU.

Production требует свежего плана, Gate A/B, отдельного nonce, резервной копии,
здоровья сайта и действующего сторожа транзакций. Установка использует существующие
блокировки публикации и базы, кратковременно останавливает только бот 266084 и
сохраняет журнал восстановления. Проверяются все логические данные CRM, HTML и
очередь незавершённых публикаций непосредственно до и после замены под блокировкой.

Откат восстанавливает только исходники и сохраняет поздние правки карточек,
страниц и очередь. Неизвестная правка исходников запрещает автоматическое
перезаписывание. Квитанция установки подтверждает исходники, запуск бота и
доступность канонических страниц. Реальная публикация и обновление интерфейса
проверяются отдельно; счётчик каталога не фиксируется на вчерашнем значении 19.

Проверки: 68 тестов исходного исправления; 17 тестов установки/отката, включая
аварийную запись, прерванную установку, повреждение бэкапа, чужую правку, сохранение
поздних изменений CRM и очереди, а также отказ при неверном URL проверки.
