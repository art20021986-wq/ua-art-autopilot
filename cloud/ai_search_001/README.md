# AI-SEARCH-001 — сайт для ИИ-чатов и Bing (пункты 3–5 ТЗ)

Основа: проверки `cloud/ai_search_probe_20261019/` (ChatGPT уже ходит, Bing — нет)
и `cloud/ai_search_source_probe_20261019/` (хэши установленных модулей = `seo_growth_001`,
главная правится счётчиками на месте, CPU 33%).

## Изменения
| Файл на сервере | Что |
|---|---|
| `ua_indexnow.py` (новый) | одна отправка списка изменённых адресов в IndexNow (Bing → ChatGPT/Copilot), таймаут 5 с, сбой не мешает публикации |
| `ua_seo_index.py` | после пересборки карты сайта шлёт в IndexNow адреса, которые появились, пропали или получили новую дату |
| `ua_seo_landings.py` | хабы «Авто из Кореи под ключ в Киеве» (uk/ru): блок «Частые вопросы» — 6 ответов только из уже опубликованных условий |
| `ua_seo_schema.py` | `faq()` — разметка FAQPage для этих же ответов |
| `video/<ключ>.txt` (новый) | ключ IndexNow (публичный по правилам IndexNow) |
| `video/index.html` | в `<head>` один блок разметки компании (AutoDealer: адрес, телефон, карта); остальное байт в байт |

Установка: бот на паузе, файлы ставятся, сразу пересобираются хабы и карта сайта
(первая отправка в IndexNow), бот запускается, проверяются хэши и публичные страницы
(главная с разметкой, хабы с FAQPage, файл ключа). CRM и карточки машин не меняются; откат автоматический.

Не входит: robots.txt (уже открыт всем), llms.txt, правки карточек.

## Замер места (решение владельца 2026-10-20)
Порог автопилота 80/90% считается от квоты аккаунта (35 ГБ, страница Files), а не от общего
диска PythonAnywhere (6 ТБ на всех клиентов, 80,4% — из-за него встала установка 39366356860).
Предпросмотр меряет `du -s -B1 /home/Carix /tmp` (как в справке PythonAnywhere), сбой замера
или превышение квоты — отказ; цифра общего диска сохраняется в доказательстве для сведения.
Ядро автопилота и пороги не менялись.
