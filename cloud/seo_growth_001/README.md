# SEO-GROWTH-001 — рост показов в Google по запросам об авто из Кореи

Задача владельца (2026-10-12): «максимальная работа на сайте, чтобы через 1–3 месяца был
прирост по ключевым словам при поиске автомобиля в Google».

## Что выяснили пробы (SEO-SOURCE-PROBE-20261012, -R2; только чтение)
- Google Search Console (2026-09-06…10-03): 5 показов, 0 кликов; карточки машин «URL неизвестен Google».
- `sitemap.xml` заморожен: каталог пишет только `publish_transaction_guard._install_catalog`,
  а обновление карты было повешено на `publikaciya._zapisat_atomarno` — для каталога не вызывается.
  В карте нет дат изменения.
- Разовые SEO-вставки прошлых задач (разметка, ссылки) стёрты пересборкой карточек.
- Карточки: заголовок без «из Кореи» и цены, нет JSON-LD, нет ссылок на страницы моделей.
- SEO-страницы моделей — 3 КБ статичного текста, на них не ссылается ни одна страница сайта,
  телефон на них отличается от сайта (…20 20 вместо …20 02).
- Отдельные украинские адреса карточек из текущих страниц не собрать: текст переводит скрипт.
- CPU PythonAnywhere: 133 из 10 000 с.

## Решение: SEO встроено в публикацию, а не вставлено в готовые файлы
| Модуль | Ответственность |
|---|---|
| `ua_seo_catalog.py` (новый) | публичные факты машин из установленного каталога; модель с учётом «А6/К5/Б-КЛАССА» |
| `ua_seo_schema.py` (новый) | JSON-LD: Car+Offer, AutoDealer, BreadcrumbList, ItemList |
| `ua_seo_landings.py` (новый) | страницы «Авто из Кореи» и по каждой модели, uk + ru, hreflang, реальные машины и цены |
| `ua_seo_index.py` (новый) | единственный писатель `video/seo/{ua,ru}/` и `sitemap.xml`; пишет только изменившееся, не удаляет |
| `ua_seo_sitemap.py` (замена) | карта: ядро + карточки из каталога + SEO-страницы, `lastmod` = дата файла |
| `ua_seo_metadata.py` (замена) | карточка: заголовок/описание с «из Кореи», ценой, «Киев»; JSON-LD; ссылки на страницы модели |
| `publish_transaction_guard.py` (+блок) | после установки каталога — `ua_seo_index.refresh`; сбой пишется в журнал и не блокирует продажу |
| `ua_crm_public_sync.py` (+1 строка) | версия SEO в ревизии карточки → штатный работник один раз переиздаёт все карточки |

Грузинские страницы `seo/gu/` не меняются; новые uk/ru страницы ссылаются на них через hreflang.
Адреса существующих страниц K5/Sonata/хаба сохранены.

## Эффект установки (нужно «да» владельца)
- Ставится только код (8 файлов), бот на паузе, CRM и страницы при установке не меняются; откат автоматический.
- Затем штатный работник переиздаёт все опубликованные карточки по одной (новые заголовки,
  разметка, ссылки), обновляет 12 SEO-страниц и карту сайта. Видимое на карточке: строка ссылок внизу.
- Установка откладывается при CPU ≥ 85%.

## Проверки

(контрольные суммы), откате установки и ограничении CPU.
