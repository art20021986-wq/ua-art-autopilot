# CARD-FACTS — две подтверждённые правки карточек (SEO-AUDIT-20261116)

Владелец, 17.11: «1. Да 2. 2021».
1. UA-0021 Sonata — ручная дата прибытия (`eta_manual`) уже прошла: очистить, чтобы карточка не обещала прошлую дату.
2. UA-0023 Kia K5 — год 2021: в текстовых полях «K5 2022» → «K5 2021». Другие «2022» не трогаются, только перечисляются в плане.

- `card_facts.py` — правила: карточки по VIN, что меняется и что разрешено писать.
- `deployment_remote.py` — проба читает строки; установка пишет «сравнить-и-записать» одной транзакцией при паузе бота,
  все остальные строки и поля CRM сверяются; откат возвращает прежние значения. Образец — `cloud/ua0025_vin_fill_001`.
- `deployment_controller.py` — после установки ждёт, пока синхронизация сайта перепубликует обе карточки
  (ru, ua и старый адрес), и проверяет, что старой даты и «K5 2022» на них нет.

Тесты `test_card_facts.py`: план, запись и откат на настоящем файле SQLite, вся установка/откат, проверка страниц.
