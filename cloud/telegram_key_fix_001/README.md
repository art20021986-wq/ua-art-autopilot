Координатор 24.11: ua_telegram_key (TELEGRAM-KEY-BOT) перехватывал и удалял любое сообщение «5–12 цифр, пробел,
16–64 буквы/цифры», например «35000 WAUZZZ8V5KA123456». Исправляет сессия 35, до пакета сессии 19 (права управляющего).

- `ua_telegram_key.py` — заменяется целиком. Ключ: цифры, затем ровно 32 hex; попытка ключа (удаляется с ответом
  «Формат не тот»): цифры, затем 28–40 hex. VIN (17 знаков) и обычный текст проходят мимо, как раньше.
- `candidate_builder.py` — ставит только если на сервере ровно файл после STAFF-FULL-ACCESS-001 (d45dd4cd: проверка
  «владелец или управляющий»), иначе отказ. Копия в пакете = тот файл + правка шаблона.
- cars_ui.py не меняется; превью проверяет, что в живом cars_ui блок подключения есть ровно один раз.
- Тесты: `test_telegram_key.py`, `test_deployment.py`. Остальное (бэкап, пауза бота, откат, проверки) — как в
  telegram_key_bot_001.
