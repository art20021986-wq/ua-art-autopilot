## Порядок закрытия Gate B

1. Получить текущий согласованный read-only снимок БД, четыре фактических модуля интеграции, пути публичных каталогов и журнал операций записи. Сверить используемую процессами БД и импортируемые файлы.
2. Сформировать из этого снимка офлайн-кандидат и точный SHA-манифест. Проверить сохранение ручных фактов, принадлежность VIN и конфликты. Восстановить копии всех текущих опубликованных карточек; черновики не публиковать.
3. Проверить каждый из десяти источников из соответствующей серверной среды на применимом автомобиле. Зафиксировать извлечение, сопоставление, причину недоступности и происхождение каждого используемого факта.
4. Проверить доступный Preview, язык, раскрытие раздела и мобильные среды. Выполнить сценарии новой карточки, изменения после ранней ошибки, удаления раздела, двух пересборок и перезапуска очереди; измерить задержки.
5. Проверить все найденные пути публикации и отката, затем предоставить поимённый отчёт по карточкам, источникам, список файлов с SHA и прошедший план возврата.
6. Только после PASS Gate B получить отдельную команду владельца на внедрение. На текущем статусе команда внедрения не запрашивается.

## Возврат и сохранность

До будущего внедрения сохранить текущие байты и SHA модулей, согласованный backup служебной БД и существующие исправные страницы. Проверить чтение новой схемы предыдущей версией приложения на копии. Схема добавляется совместимо; автоматически удалять новые столбцы, факты, ручные значения или журнал при откате нельзя.

При ошибке локальной транзакции reconciler восстанавливает только собственные неизменённые после записи файлы, не затирая чужую параллельную правку. Ошибка публичной проверки сохраняет корректные локальные факты/HTML и возвращает FAIL для ограниченного повтора. Успех не объявляется по одному факту записи файла.

Откат приложения должен сохранять защиту раздела и запрет рекламы. Возврат старого полного HTML без проверки спецификации не допускается. Точный исполняемый сценарий возврата пока не утверждён: он зависит от фактических файлов сервера и должен пройти Gate B на их копии.
