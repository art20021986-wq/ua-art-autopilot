# CRM и дополнительная спецификация: порядок восстановления

**Это инструкция к подготовленному исправлению. В рабочей CRM оно ещё не подтверждено; Gate B не объявлен пройденным.** Команда владельца на размещение уже получена. Год UA-0016 …1028 подтверждён: **2017**; пока это поправка Preview, рабочее значение требует отдельного применения в допущенном этапе.

## Что должно получиться

На карточке остаётся **один видимый VIN** и отдельный раскрываемый раздел **«Додаткова специфікація» → «Переглянути характеристики»**. Сохранение нового автомобиля или значимых изменений запускает сбор автоматически. Для опубликованной карточки обновление раздела выполняется отдельно от сбора и повторяется после временного сбоя. Нажимать «Дополнительная спецификация» для этого не требуется.

Фото, видео, цены, доставка, диагностика, стили и остальные элементы сохраняются. Внешняя реклама к VIN не добавляется. Ошибка источника не стирает сохранённые характеристики; ручные значения защищены. Скрытая или удалённая карточка не возвращается на сайт из-за фоновой обработки.

## Что нажимать после внедрения

Названия ниже найдены в проверенном коде CRM; их отображение в работающем боте ещё предстоит подтвердить.

| Задача | Действие владельца | Ожидаемый результат кандидата |
|---|---|---|
| Добавить автомобиль | Открыть обычное создание карточки, внести VIN и данные, завершить сохранение | Новая карточка и автоматическая задача сбора; черновик сам не публикуется |
| Исправить данные | **«Редактировать данные»**, затем сохранить правку | Проверка нового контекста; устаревший ответ не подменяет новые данные |
| Подготовить публикацию | **«Разместить объявление»**; если CRM перечисляет недостающие поля — **«Дозаполнить»** | Проверка заполненности по действующему правилу CRM |
| Разместить | **«Показать в каталоге»** в объявлении либо **«Показать клиентам»** в карточке | После успешной проверки — карточка в каталоге и рабочая HTML-ссылка |
| Проверить вид | **«Как видит покупатель»** | Просмотр карточки; раскрытие спецификации проверяется на её странице |
| Временно убрать | **«Скрыть от клиентов»** | Карточка исчезает из каталога; данные сохраняются, фоновые задачи не публикуют её повторно |
| Зафиксировать продажу | **«Продано»**, затем подтверждение действия в боте | По существующему сценарию карточка убирается из каталога; история сохраняется |
| Удалить карточку | **«Удалить»**, затем подтверждение | Удаление проходит согласованно с публикацией; факты и резерв сохраняются служебно, фоновые задачи карточку не воссоздают |

Для существующих опубликованных карточек отдельный ручной запуск спецификации не нужен. «Характеристики собраны» и «страница обновлена» — разные результаты: ошибка второго шага должна оставаться видимой, даже если сбор завершён.

Удалённый номер UA-XXXX сохраняется в служебном реестре и **не используется для другого автомобиля**. Это предотвращает присвоение новому авто старых характеристик. Возврат после сбоя восстанавливает только изменения своей операции и не затирает чужую одновременную правку. Самовольного восстановления удалённой карточки нет.

Действующий генератор проверен: после удаления последнего номера он мог выдать его повторно. Подготовлен постоянный счётчик в CRM и согласованные исправления трёх фактических путей создания. Резервирование номера и сохранение карточки выполняются в одной транзакции; подтверждённые номера сохраняются после удаления. Исторический удалённый номер, не оставивший записи ни в одном доступном реестре, восстановить автоматически невозможно. [Исправление нумерации и проверки](Card-number-recovery.md). Полный цикл через работающий бот пока не объявлен завершённым: исправление ещё не внедрено.

## Этапы и условия готовности

1. **Завершить серверную проверку.** Получить фактический PASS из изолированной серверной среды; загрузка пакета сама по себе не является результатом.
2. **Сверить текущую CRM и сайт.** Зафиксировать расхождения 18 записей CRM и обеих папок сайта: данные, каталог, диагностика, VIN и спецификация. Свежие результаты добавляются отдельно; исторические HTML не выдаются за текущие.
3. **Закрыть оставшийся Gate B.** Проверить действующие пути публикации/возврата, источники и сроки восстановления; установить допустимый маршрут при существующем EMERGENCY_HALT. Локальные тесты и Preview не отменяют эти условия.
4. **Внедрить по уже полученной команде.** С резервом применить точную правку года UA-0016 и утверждённый пакет, затем проверить реальные карточки: один VIN, видимый раздел, сохранность остальных данных. При сбое выполнить проверенный возврат.
5. **Отдельно закончить UA-0017/UA-0018.** После свежей проверки недостающих данных подготовить их публикацию. Их статус черновика не меняется автоматически в ходе восстановления остальных карточек.

Вопросы владельцу нужны только по фактическим деловым расхождениям: например, какая из двух обнаруженных цен верная или каков отсутствующий пробег. Каждый вопрос должен содержать номер автомобиля и конкретные наблюдённые значения. Повторное подтверждение **2017 года** или уже полученной команды размещения не требуется.
