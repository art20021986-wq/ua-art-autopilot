Независимо прочитаны runner, построитель пакета и используемый `make_audit_guard`. Проверен фактический ZIP: ровно 11 записей, SHA и длины всех файлов соответствуют манифесту, `guard_support.py` совпадает с существующим `server_gate.py`. Нового publisher-cycle harness в пакете нет. SHA ZIP следует сверить после передачи, до выполнения: внутренний манифест описывает пакет, а проверенная внешняя SHA связывает его с этой проверкой.

Подтверждённый объём выполнения:

- Фиксированный рабочий каталог `/home/Carix/spec_retry_v8_20260909`, права 0700, Python 3.10. Команда пакета: `python3.10 -I -B retry_gate.py`.
- Читается только прежний подготовленный каталог `compiled-candidate` запуска v7 и его манифест. Десять модулей проверяются по постоянным SHA; состав каталога проверяется полностью. После тестов сравниваются байты и времена модификации этих входов.
- В новом каталоге запуска создаётся копия десяти модулей. Только `vin_spec_service.py` заменяется проверенным v8 с SHA `a4468d2de5fd35d0778dea0ee15ad382dcb680ec4aa344da217cfce67f088c16`. Существующие v7 и production-файлы не заменяются.
- Запись ограничена новым стендом и отдельным личным временным каталогом. Сетевые действия и все дочерние процессы запрещены, включая ранее разрешённую вспомогательную проверку блокировки. Чтение рабочих файлов в `/home/Carix` запрещено; исключение относится только к точным файлам прежнего подготовленного кандидата. Импорт или компиляция модулей из прежнего каталога не разрешаются: выполняется новая копия.
- Запускаются только три заданных тестовых модуля. Для PASS нужны ровно 50 успешных проверок, отсутствие пропусков и нулевые счётчики запрещённых действий. Повторно проверяются пакет, предыдущие входы и неизменность нового runtime.

Просмотрен локальный протокол `worker-cooldown-v8-runner-qa.json`: 50/50 PASS, все четыре счётчика I/O равны нулю, прежние байты/mtime и новая копия неизменны. Протокол явно помечен как локальный Python 3.12 с заменой путей только в QA-копии; **это не серверный результат PythonAnywhere**. Проверенный ZIP после такого прогона не изменялся.

Проверка применяется к доверенному пакету указанных SHA и выявлению случайных внешних действий тестов. Общий Gate B, реальные сетевые источники, рабочая CRM и измеренный серверный SLA этим заключением не подтверждаются. Следующим доказательством должен быть отдельный `retry-gate-result.json` фактического разрешённого запуска на Python 3.10.
