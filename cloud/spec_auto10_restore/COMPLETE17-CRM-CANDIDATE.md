# Установочный состав complete17 v3

`complete17_crm_candidate.py` создаёт отдельную версию `UA-ART-SPEC-AUTO10-COMPLETE-17-V3`. Базовый состав final17 v2 и его прежние серверные артефакты остаются неизменными.

Проверенный манифест v3: `14f42086fc8bc94aefc4e4c83bda50e01107c30d2ad893c00d658f60d0c64fff`. SHA карты всех 17 файлов: `b519021118fa849b1229dc861ffd9483caee2f2ae211061bcd56c5fe89a8a450`. Чистый сборщик: `6b78ac67a6259cb8c49968fe16378203e6c1d15ef2eee63ef6a416c3d22500eb`.

Из 17 устанавливаемых файлов меняется только `cars_ui.py`: отменённая правка спецификации больше не перехватывает последующее редактирование обычного поля CRM. Новый SHA: `57ad5acc340d412aa9d95e1ef56c7de85d4346ad6bbc755fda311763f3637a42`. Остальные 16 файлов, включая publisher, worker, allocator, аналитику, обработку VIN и вложенный installer TASK083, побайтно совпадают с final17 v2.

Новый манифест содержит два самостоятельных основания проверки:

1. `execution_evidence.combined_v2`: прочитанные серверные протоколы прежнего общего цикла exact final17 v2, с явным ограничением относительно заменяемого старого `cars_ui`.
2. `execution_evidence.callback_delta`: отдельный серверный опыт над тем же v2 с единственной заменой `cars_ui`; фактические регистрация, callbacks, БД и publisher с моделируемым Telegram транспортом и чтением локального HTML.

Оба результата связаны точными SHA протоколов, исходного манифеста и применённого патчера. Они не превращаются в новый запуск неизменного общего цикла и не объявляют общий Gate B завершённым. Реальные Telegram/API, фоновые тайминги, внешние источники, завершение старых процессов, установка и публикация UA-0017/UA-0018 остаются самостоятельными проверками.

Сборщик принимает только исходный манифест `12afce821b784771a2a8a0415cc289f5e713d53aabedf0ed3e2747a8c4d4e136`, точный набор 17 файлов и точные серверные receipts. До их фактического чтения выходной каталог не создаётся. Изменённые файлы, недостающий вложенный installer, лишние файлы, подменённый PASS, символические ссылки, существующий выходной каталог и пересечение с исходниками отклоняются.

Все Python-файлы компилируются без импорта приложений. Выходной каталог создаётся эксклюзивно, манифест записывается последним, затем весь состав повторно проверяется. При ошибке удаляется только собственный маркер готовности; чужие файлы не удаляются.

Четыре проверки `tests/test_complete17_crm_candidate.py` прошли: состав, изменение входных байтов/пропажа вложенного installer/лишний файл, подменённый PASS и существующий выходной каталог/пересечение через `..`/символическая ссылка. Журнал: `evidence/complete17-v3-composition-tests.log`. При намеренном отклонении symlink старый закреплённый helper выдал предупреждение о закрытии итератора `scandir`; оно не изменило результат отказа. Исторический helper не редактировался.

Это не повтор старых функциональных циклов ради количества тестов. Новая версия передана для закрепления точного SHA манифеста в admission штатного установщика, чтобы он не установил прежний `cars_ui`.
