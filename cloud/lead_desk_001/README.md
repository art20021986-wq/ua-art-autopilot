# ORDER-PROCESS-001 — заявки с сайта в CRM-боте: статус, срок ответа, заметка, напоминания

Задача и решения владельца: `tasks/ORDER-PROCESS-001.md`. Живые исходники прочитаны пробой
`cloud/lead_desk_probe_001/20261105.json`.

Модули (каждый — одна ответственность):
- `ua_lead_calendar.py` — рабочие дни (пн–сб, праздники ст. 73 КЗпП на любой год) и срок ответа (3 полных рабочих дня).
- `ua_lead_desk_store.py` — состояние заявки в своих таблицах crm.db (статус, заметка, клиент, отправленные напоминания).
- `ua_lead_desk_view.py` — тексты и кнопки (список, карточка, напоминание, карточка клиента).
- `ua_lead_desk.py` — Telegram: кнопки, заметка, перенос в «Клиенты», напоминания раз в 15 минут (9:00–20:00 Киев).
- `ua_site_leads.py` — заменяет живой: кнопка «Заявки с сайта» ведёт в новый экран; старый экран заявок остаётся
  зарегистрированным, чтобы прежние кнопки работали.
- `candidate_builder.py`, `deployment_*`, `make_release.py` — установка по образцу `cloud/crm_photo_card_001`
  (бэкап, пауза бота, блокировки, проверка, откат).

Тесты: `test_lead_calendar.py`, `test_lead_desk.py`, `test_deployment.py`.
