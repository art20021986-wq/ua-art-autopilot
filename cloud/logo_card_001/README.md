# LOGO-CARD-001 — кнопки «Головна» / «Назад» на карточках авто

Пожелание владельца 28.11: на карточках авто — те же кнопки «Головна» / «Назад» в шапке, что в каталоге.
Ждёт «Да» владельца. Пакет НЕ запущен.

## Почему на карточках не было кнопок
LOGO-001 ставит кнопки прямо перед переключателем RU/UA/GE. Карточку пишет цепочка
`ua_mobile_comfort(ua_lang_bar(ua_layout_reserve(ua_brand_home(html))))`: кнопки (внутри `ua_brand_home`) ищут
переключатель, а его пишет `ua_lang_bar` позже — перед `<div class='svyaz'>`. Переключателя ещё нет — кнопок нет.

## Что меняется
| Файл на сервере | Что |
|---|---|
| `ua_header_nav.py` (замена версии LOGO-001, хеш 3ba992f4) | нет переключателя — кнопки перед `.svyaz`; `ua_lang_bar` ставит переключатель сразу за ними. Страницы с переключателем — как сейчас |
| `ua_seo_metadata.py` (хеш 7a07a19e, версия LOGO-001) | только строка `SEO_REVISION = 'LOGO-CARD-001'` — CRM один раз пересоберёт карточки |

Страницы сайта установка не пишет. Тексты, ссылки, фото, логотип, переключатель и данные CRM не меняются.
Бэкап, пауза бота, замки записи, откат байт в байт, проверки здоровья и сторож транзакций — как в LOGO-001.

## Проверки
- `test_release.py`: свежая карточка без переключателя (`card_no_switch_UA-0001.html`, 28.11) через `ua_brand_home`
  и `ua_lang_bar` (и всю цепочку) — кнопки один раз, сразу перед переключателем, остальное байт в байт; повтор ничего
  не меняет; страницы с переключателем (главная, каталог, карточка UA-0023, подбор, SEO-страница) — как раньше.
  Модули LOGO-001 и PERF-CWV-001 берутся из их пакетов и сверяются по хешу.
- `test_deployment.py`: установщик (бэкап, пауза бота, замки, откат, сбои), превью на копии сервера, публичные проверки.
- Превью на сервере: каждая живая страница (video, video/ua, video/ru) получает от нового модуля то же, что сейчас;
  свежая карточка через установленную цепочку — кнопки перед переключателем, остальное байт в байт.
- После установки: index — без кнопок, katalog — кнопки (обязательные проверки). Карточка `ua/UA-0001.html` — кнопки
  сразу перед переключателем: появится только после пересборки CRM, поэтому синхронно не гарантируется — ждём до
  10 минут; не успела — в квитанции `PENDING_CRM_REPUBLISH`, проверить потом отдельной проверкой на чтение. Кнопки
  не на месте — ошибка.

## Запуск (после «Да» владельца и «можно» координатора)
1. Превью: `python3 cloud/logo_card_001/make_release.py launch LOGO-CARD-PREFLIGHT-20261128`.
2. После превью и «да»: `python3 cloud/logo_card_001/make_release.py install` → `LOGO-CARD-INSTALL-20261128`.

Откат возвращает оба файла байт в байт; по старой `SEO_REVISION` CRM должна снова пересобрать карточки (без кнопок).
