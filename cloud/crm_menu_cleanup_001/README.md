# CRM-MENU-CLEANUP-001 — убрать из меню CRM «Ещё», «Запуск оптимизации», «Отчёт по клиентам»

## Где это в коде (исходники бота, cars_ui.py)
Все три кнопки и вход в «Ещё» добавляет одна функция `with_stats_button`:
к рабочим кнопкам меню она дописывает «Отчёт по клиентам», «Запуск оптимизации»
и, если есть кнопки из списка `MORE`, — «Ещё» (подменю `more_screen`:
Клиенты, Заявки из бота, На проверке, Сводка по базе, Сотрудники, Поиск).

## Правка (одна функция, один файл)
`build_cars_ui.py` в точной установленной версии `cars_ui.py`
(sha ce0d1327…, после CRM-FIELD-INPUT-INSTALL-20261012-R4) заменяет только
`with_stats_button`: она по-прежнему убирает кнопки `HIDE`, теперь убирает и
кнопки `MORE` и больше ничего не дописывает. Остальной код не трогается;
старые обработчики остаются, поэтому кнопки в старых сообщениях чата не ломаются.
Только стандартная библиотека. 5 тестов (включая воспроизведение скриншота).
