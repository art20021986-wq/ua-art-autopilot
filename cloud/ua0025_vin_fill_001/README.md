# UA0025-VIN-FILL — пустые основные поля UA-0025 по VIN

Владелец, 13.11 (ответ 3 по NEW-CAR-VIN-SPEC): «дозаполнить пустые поля UA-0025 — да».

- `vin_fill.py` — какие поля пустые и чем их заполнить (только пустые; карточка и VIN проверяются).
- `deployment_remote.py` — проба читает строку UA-0025 и расшифровывает VIN установленным `ua_vin_decode`
  (отдельный python3.10); установка пишет поле за полем «сравнить-и-записать» одной транзакцией, все остальные
  строки и поля CRM сверяются; откат возвращает прежние (пустые) значения. Бэкап, пауза бота, блокировки — как в
  шаблоне `cloud/fuel_normalize_001`; связь с сервером — из `cloud/crm_new_car_vin_002` (повтор DELETE, уборка).
- Запись в CRM разрешена явно: `allow_crm_vehicle_data` в запросе и `explicit_crm_vehicle_approval` в манифесте.

Тесты `test_vin_fill.py`: план, запись и откат на настоящем файле SQLite, вся установка/откат на реальном плане.
