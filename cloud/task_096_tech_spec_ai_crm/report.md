## 2. Что фактически выполнено в этом раунде
- Спроектирована sandbox-схема `additional_specification` (файл `schema_additional_spec.sql`), строго отделённая от основных (операторских) полей CRM, с встроенным `CHECK (is_price_field = 0)` и таблицей `price_denylist`.
- Реализован модуль дедупликации (`dedup_check.py`) с картой синонимов технических характеристик, блокирующий:
  - запись факта, уже присутствующего как ручное операторское поле;
  - семантический дубль в самой «Дополнительной спецификации».
- Реализован модуль жёсткого исключения цены закупки (`price_exclusion_guard.py`) — по ключу поля и по подстрокам, включая русскоязычные варианты.
- Реализован модуль защиты ручных полей (`manual_field_protection.py`) с замороженным списком операторских ключей.
- Подготовлен offline self-test harness (`selftest.py`), создающий синтетическую in-memory базу по образцу UA-0001…UA-0016 (без реальных данных клиентов) и проверяющий все шесть сценариев (дубль ручного поля, новый факт, семантический дубль, запрет цены, блокировка первичного ключа, неизменность реестра первичных полей).
- Подготовлен непубличный HTML-canary (`canary_preview.html`) с `noindex`, демонстрирующий новый блок «Дополнительная спецификация» на примере UA-0009, без изменения основного блока карточки.
- Подготовлен скрипт проверки доступности двух утверждённых источников (`source_check.py`).
- Сформирован файл машинных свидетельств (`evidence.json`), честно отражающий, что именно было выполнено, а что осталось на исполнение контроллеру.

## 3. Что НЕ было выполнено и почему
В данной среде выполнения Claude/Cloud нет:
- доступа к реальному файлу CRM SQLite (даже в режиме `mode=ro`),
- доступа к файловой системе `/home/Carix/...`,
- исходящего сетевого доступа для проверки двух источников,
- возможности запускать код (интерпретатор Python) в рамках этого канала доставки.

Поэтому:
- backup рабочей CRM не создавался Claude/Cloud (нет доступа) — это должен выполнить контроллер/процесс с реальным доступом;
- self-test harness и source_check.py подготовлены, но не выполнены Claude — их должен запустить контроллер и приложить реальный результат в `evidence.json`;
- никакие реальные значения полей UA-0001…UA-0016 не читались и не изменялись.

## 4. Гарантии безопасности, встроенные в код
- Схема не содержит колонок для цены закупки/аукциона/опта; попытка вставить такое поле блокируется на уровне `CHECK` и на уровне Python-guard.
- Основные (операторские) поля никогда не являются целью записи модулей AI/индексации — попытка записи в них вызывает исключение `ManualFieldViolation`.
- Все отклонённые попытки записи логируются в `additional_specification_rejections` без сохранения значения цены.
- HTML-canary помечен `noindex`, не связан ни с одной публичной страницей и не публиковался.
