# STAFF-FULL-ACCESS-001 — BOT CRM: у управляющего всё как у владельца

Владелец 2026-11-24: «у Олега должно быть всё то же самое, как у меня в боте CRM, у меня владелец, у него
управляющий». Роли не меняются: владелец — «👑 Владелец», Олег — «🛡 Управляющий администратор».

- `ua_full_access.py` — одно правило: полные права у «Владельца» и «Управляющего администратора»;
  `ids()` — кому слать уведомления владельца (vladelec.txt первым + все активные владельцы и управляющие CRM).
- Точечные правки (`edit_*.py`, по точному контексту, без старых одиночных проверок):
  `team_bot.py` (проверка владельца + 5 уведомлений), `cars_ui.py`, `cars_schema.py` (деньги в карточке),
  `ai.py` (черновик ИИ), `ua_home_photo_bot.py`, `ua_home_stage_bot.py`, `ua_kr_prices_bot.py`,
  `ua_telegram_key.py`, `ua_pay_bot.py` (уведомление об оплате), `bezopasnost.py` (охрана: уведомления,
  `/dostup`, `/kopiya`; ничего не отключается), `svyaz.py`.
- Записей в CRM нет. Владельца по-прежнему нельзя заблокировать; управляющего блокирует владелец.
- Черновики у каждого свои (`user_data`), параллельная работа не мешает.

Клиентский бот — следующий шаг (`cloud/staff_full_access_001`).
Тесты: `test_ua_full_access.py`, `test_edits.py`, `test_deployment.py`.
