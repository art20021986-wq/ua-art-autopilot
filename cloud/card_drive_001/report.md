# CARD-DRIVE-001 — проба (17.11, только чтение, production не менялся)

## Живой сайт
Проверены все карточки из sitemap: 18 авто × 3 страницы (`/video/UA-XXXX.html`, `/video/ru/…`, `/video/ua/…`) = 54.
Во всех 54 в блоке «Коротко» есть строка привода, сразу после коробки:
Пробег · Двигатель · Коробка · **Привод** · Цвет · VIN (uk: Пробіг · Двигун · Коробка передач · **Привід** · Колір · VIN).
Значения: UA-0001 задний; UA-0017 полный; остальные передний. Пустых нет.
Грузинский — переводчик сайта `ua-site-languages.js`: «Привод» → «ამძრავი», передний → «წინა», задний → «უკანა», полный → «სრული».
«Коробка передач — автомат» без привода, о которой писал координатор, — это текст описания; в UA-0001 там же
следует «Привод — задний».

## Код
`stranica.py` (копия `cloud/card_lead_001/fixtures/stranica.txt`, 15.11): блок «Коротко» выводит
`("Коробка","gearbox"), ("Привод","drive"), ("Цвет","color"), ("VIN","vin")` — строка только при заполненном поле.
Бот новых авто (`ua_vin_decode.py`, сессия 16) пишет в CRM «передний / задний / полный»
(`test_vin_decode.py`). Значит, новые карточки тоже получают привод.

## Недочёт (не входит в задачу, предложить отдельно)
UA-0021 и UA-0022: в CRM привод записан с большой буквы «Передний». Переводчик сайта знает только «передний»,
поэтому на украинской (и грузинской) версии написано по-русски «Передний» (снимок `ua-0021-uk.png`).
Исправление — запись в CRM (2 карточки, поле привода → «передний») и пересборка двух карточек; только по «да» владельца.

Снимки: `ua-0017-uk.png` (полный → «повний»), `ua-0021-uk.png` («Передний» без перевода).
