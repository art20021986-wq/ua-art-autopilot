Причина: охранный модуль `bezopasnost.py` не пропускал незнакомого человека с кодом из «👥 Сотрудники» →
«➕ Добавить …», поэтому код не доходил до CRM-бота (проба R8/R9).
- `ua_staff_invite.py` — только чтение: код есть в crm.db, не использован, создан не раньше 24 часов назад.
- `candidate.py` — один блок в `bezopasnost.py` перед отказом: такой код идёт дальше в CRM-бот, тот выдаёт роль.
  Чужие без кода по-прежнему не проходят, владельцу по-прежнему приходит уведомление.
Тесты: `test_staff_invite.py`, `test_deployment.py`.
