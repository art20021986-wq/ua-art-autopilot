# Перенос «Авто под заказ» в клиентский бот

Раздел и очередь уведомлений перенесены из CRM в клиентский бот. Доступ есть
только у владельца в личном чате. При каждом открытии/обновлении проверяется
получатель. Кнопка возврата открывает действующее меню `v_start`.

Хранилище заявок не меняется: первая существующая заявка сохраняет ID, номер,
данные и историю отправки. Новые заявки отправляются владельцу клиентским ботом
через существующий outbox и JobQueue. Зависимости не добавлены.

`deploy.py` проверяет исходные SHA семи файлов, сохраняет приватную резервную
копию и атомарно заменяет каждый файл. Из посторонних функций хостов ничего
не меняется. Ранее удалённые шесть ссылок клиентского меню не восстанавливаются.

Архив для установки содержит только четыре изменённых модуля `ua_order`:
`host.py`, `bindings.py`, `crm.py`, `telegram.py` из `order_eight_countries_001`.
Предварительная проверка: `python3.10 -S client_order_inbox_deploy.py client_order_inbox.zip`.
Для установки используется тот же вызов с `--install`, затем обычный перезапуск
существующей службы. Установщик не управляет службами и не отправляет сообщений.

Проверки: 45 тестов существующего пакета, включая доступ владельца, отказ
постороннему пользователю и группе, сохранность существующей заявки, повтор
после ошибки доставки и восстановление после фиксации квитанции. Проверка
приватных исходников подтверждает сохранность 294 посторонних узлов AST.

Использованы официальные интерфейсы:
- https://docs.python-telegram-bot.org/en/stable/telegram.ext.application.html#telegram.ext.Application.add_handler
- https://docs.python-telegram-bot.org/en/stable/telegram.ext.jobqueue.html#telegram.ext.JobQueue.run_repeating
- https://core.telegram.org/bots/api#inlinekeyboardmarkup
