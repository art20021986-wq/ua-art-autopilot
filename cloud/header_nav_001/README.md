# HEADER-NAV-001 — две кнопки под логотипом (макеты, на сайт не ставились)

Владелец 28.11 (через координатора): «под логотипом два клика: главная и вернуться назад, дизайн мирового уровня».
Сейчас «← На головну» в шапке — CSS `a.brand .brand-copy::after` (ua_brand_home), на всех страницах кроме главной.
Макеты (iPhone 13, 390 px, живой katalog.html + новый логотип C): header_nav_variants.png
1) «Назад» контуром + «Головна» золотая (две таблетки 44 px); 2) одна капсула из двух половин; 3) круглые значки 44 px
с подписями. Касание ≥44 px (Apple HIG 44 pt, Material 48 dp), иконки стандартные (‹ и дом), подписи uk/ru/ka.
«Назад»: history.back(), если пришли с uaart.com.ua (document.referrer), иначе — на главную. На главной кнопок нет.
Установка — вместе с логотипом LOGO-001 одним пакетом после «Да» владельца на превью.
