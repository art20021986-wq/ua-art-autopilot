# Owner policy candidate — NOT INTEGRATED / NOT DEPLOYED

Статус: локальный кандидат в отдельный пакет. Автопилот, Telegram, CRM и сайт
этот код не вызывают. Runtime manifest, workflows и production не изменены.

Дополнение по ответу владельца: `price_captions.py` задаёт проверенные RU/UA
подписи — Украина с растаможкой в Украине, Грузия без растаможки в Грузии.
Модуль не меняет суммы и не подключён к рабочему генератору. Включение доставки,
сертификации и отсутствие иных доплат этим ответом не подтверждены.

## Зафиксированные правила владельца

- Любой сбой: STOP и событие FAILURE; немедленных автоматических повторов нет.
- Возобновление — только после устранения причины и свежих успешных проверок,
  для той же задачи/request/попытки и следующего доказанно не начатого действия.
  Завершённые действия не повторяются; неопределённый результат записи требует
  reconciliation, не повторной записи. Терминальные задачи не возобновляются.
- Для production дополнительно нужны проверенные backup, rollback, существующий
  Gate B receipt и разрешение владельца. Модуль их не создаёт и не подтверждает.
- Независимая работа допустима только при свежем доказательстве изоляции,
  непересекающихся канонических ресурсах и точных проверенных FINISHED receipts
  зависимостей. Общие control-plane/global scopes консервативно блокируют работу.
- Telegram: только ошибки и ежедневный краткий отчёт со ссылкой на подробный,
  лично владельцу в CRM-бот. Время отчёта — 10:00 Asia/Ho_Chi_Minh; работа — 24/7.

## Контракт и ограничения

`failure_decision`, `resume_decision`, `independent_task_decision` и
`telegram_event_selected` — чистые функции. Результат `*_ELIGIBLE` означает
только соответствие переданным фактам, **не выполненную операцию**. Все обязательные
факты передаются явно: нет переключателя, включающего auto-resume по умолчанию.
Булевы поля принимают только `bool`, не 1/0/строки; обязательны непустые identity,
SHA-256 bindings и timestamps с часовым поясом. Некорректные входы вызывают
`PolicyInputError`; будущая интеграция обязана считать это STOP/WAIT, не обходить.

Свежесть ограничена пятью минутами — консервативная граница этого кандидата,
не доказательство свежести live-проверок. Хеши — только ссылки на доказательства:
независимый доверенный адаптер должен проверить реальные байты, timestamp,
соответствие identity и источники. Кандидат не проверяет подлинность сам.

Отсутствуют: сетевые вызовы, запись файлов, секреты, scheduler, Telegram sender,
разрешение получателя, доставка/дедупликация уведомлений, автоматическое снятие
HALT, dispatch, восстановление, locks и атомарные транзакции. Канонические resource
scopes должен предоставлять проверенный адаптер; перечисление ресурсов по одному
текстовому названию не доказывает независимость.

## Локальная проверка

Из каталога пакета:

```sh
python -B -m unittest -v test_owner_policy.py
```

До подключения обязательны отдельная ревизия, живые интеграционные проверки,
устранение 7 существующих FAIL workflow-контрактов, проверка runtime registration
и Gate B. Обходить защиту или править manifest ради зелёных тестов запрещено.
