# HOME-PHOTO-001 — кнопка «Фото главной страницы» в CRM

Владелец (2026-10-28): кнопка в CRM, чтобы загрузить фото, и оно стояло на
главной странице: машина по центру, лишнее по краям убрано.

## Как работает
1. В главном меню владельца — кнопка «🖼 Фото главной страницы».
2. Бот просит фото (лучше файлом — без сжатия Telegram).
3. Машина находится нейросетью, кадр 3:2 ставит её по центру с небольшим
   запасом по краям, лишнее обрезается (до 1800×1200, JPEG).
4. Бот показывает результат: «✅ Поставить на главную» / «🔄 Другое фото» / «Отмена».
5. После «Поставить» меняется только фото первого экрана главной; копия
   `index.html` до изменения сохраняется в `/home/Carix/ua_home_photo/backup/`,
   старые фото остаются в `video/order/` (любое можно вернуть).

Другие фото, которые владелец шлёт боту, по-прежнему уходят в CRM. Пока бот ждёт
фото для главной (до 15 минут), любое другое сообщение отменяет ожидание.

## Модули (у каждого одна задача)
| Файл на сервере | Задача |
|---|---|
| `ua_home_photo_crop.py` | фото → найти машину → кадр 3:2 → JPEG; ничего не пишет |
| `ua_home_photo_site.py` | положить JPEG в `video/order/home-<хэш>.jpg` и поменять `<picture>` первого экрана + один CSS-блок; бэкап, атомарная запись, отказ если страница изменилась |
| `ua_home_photo_bot.py` | диалог в Telegram: кнопка, приём фото, предпросмотр, подтверждение |
| `cars_ui.py` | только дописанный в конец блок: кнопка в меню владельца и регистрация обработчиков (как уже сделаны прежние расширения `register`) |
| `ua_home_photo/object_detection_yolox_2022nov.onnx` | модель YOLOX-S из OpenCV Model Zoo (Apache-2.0), закреплена коммитом и sha256 |

## Почему так
- Новых библиотек нет: на сервере уже есть Pillow 10.4 и OpenCV 4.10 (проба
  HOME-PHOTO-PROBE-20261028); модель запускается штатным `cv2.dnn`, разбор
  выхода — как в официальном демо OpenCV Model Zoo.
- NanoDet (3,8 МБ) проверен и отклонён: в сборке Model Zoo нет слоя для крупных
  объектов, рамка обрезала края машины. YOLOX-S даёт плотную рамку по кузову
  (проверено на десятках фото машин из галереи сайта).
- Модель загружается только при обработке фото (бот не держит ~100 МБ в памяти).
- Имя файла фото по хэшу — браузеры не покажут старое фото из кэша.

## Установка
Пакет по образцу `cloud/crm_card_sold_001`: превью (сборка кандидата из точных
установленных исходников + пробный запуск нейросети в python3.10 на живом фото
главной и правка главной в памяти), затем после «да» владельца — бэкап, пауза
бота, запись файлов, проверка, запуск бота, откат тем же пакетом. Установка сайт
не меняет; фото на главной меняет владелец кнопкой.

Источники: OpenCV Model Zoo object_detection_yolox (README, demo.py, yolox.py),
python-telegram-bot v22 (handler groups, ApplicationHandlerStop), Telegram Bot API
(getFile ≤ 20 МБ), Pillow ImageOps.exif_transpose.
