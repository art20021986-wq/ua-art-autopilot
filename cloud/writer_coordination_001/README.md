# Координация записи: подготовленные исправления

9 сентября 2026. Рабочие процессы, расписания, HTML, CRM и HALT не изменялись. Код в этом каталоге не подключён автоматически к production.

**Подтверждённая проблема:** WSGI-аналитика читает и заменяет HTML без общей блокировки. Новая публикация между этими действиями может быть затёрта старым содержимым. TASK083 также управляет каталогами и генераторами отдельно от publication-lock. Историческая причина исчезновения конкретной спецификации не установлена.

Подготовлены два точных патча участия в общей блокировке, серверный holder существующих inode с постоянным intent и контроллер паузы/возврата четырёх существующих задач. Патчи не меняют очередь, не снимают HALT и не заменяют проверку завершения старых процессов.

Это разные области проверки. Их нельзя складывать в общий production PASS. Ни живой PATCH конфигурации задач, ни перезагрузка WSGI, ни установка нового пакета не выполнялись.

Главные документы:

- `WRITER-SCOPE.md` — проверенные писатели, точные SHA и границы очереди/аналитики/диагностики.
- `PLATFORM-CONTROL.md` — сохранение ID, настроек, неопределённых результатов и терминальное возобновление.
- `TASK083-WRITER.md` — допуск cron/install/rollback к общей публикации.
- `REVIEW.md` — независимые проверки и устранённые дефекты.
- `NEXT-INTEGRATION-PLAN.md` — точные оставшиеся шаги подключения.

Текущий `EXTERNAL_WRITER_VERIFICATION_REQUIRED` в main остаётся: ещё нет подключённого доказательства завершения всех прежних писателей, проверенной передачи окна установщику и свежего server-proof перед Git CAS. Снятие этой строки само по себе устранило бы проверку, но сохранило бы подтверждённую гонку данных.

Подготовка и изолированные проверки уже разрешены владельцем. Новое общее ТЗ не требуется. Точная команда для рабочего recovery запрашивается только после готовности исполняемого плана и всех его обязательных проверок.
