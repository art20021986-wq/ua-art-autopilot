# Одноразовый приём GitHub read credential

Пакет принимает **уже созданный владельцем** fine-grained GitHub token. Для
планируемого reader владелец разрешает только репозиторий
`art20021986-wq/ua-art-autopilot` и `Contents: read`. Офлайн-приёмник проверяет
формат, но не может подтвердить фактические разрешения или срок действия ключа.
Он не обращается к сети, не ищет другие ключи, не включает reader или Production.

После загрузки проверенного файла в Bash-консоли аккаунта Carix выполнить:

```bash
python3 -I -B /home/Carix/autopilot_inbox/cloud/provision_read_credential.py
```

Дождаться `GitHub read-only token (hidden):`, затем **самому владельцу** вставить
ключ и нажать Enter. Ключ не передавать в чат, аргументы команды, переменные
окружения или перенаправление ввода. Успех имеет единственный вывод:
`UAART_READ_CREDENTIAL_READY`.

Файл создаётся по фиксированному пути
`/home/Carix/.config/uaart-price-control/github-read.token`: директория `0700`,
файл `0600`, владелец — текущий пользователь. Все компоненты пути открываются
без перехода по symlink; существующий файл любого типа не перезаписывается.
Существующая `.config` может быть `0755`; её права не меняются. Групповая или
общая запись в `.config` или домашний каталог запрещена.

Приём требует настоящий управляющий TTY. Запасной режим getpass с видимым вводом
запрещён. Обработанный Ctrl+C/EOF выдаёт `E_INPUT_ABORTED`; пустой, многострочный
или неподходящий ввод — `E_TOKEN_FORMAT`. Ошибки не содержат текста исключений
или ключа. Запись идёт в приватный временный файл; финальное имя появляется
атомарно после fsync и проверки прочитанных байтов. Конкурирующая запись не
перезаписывается и не удаляется.

При SIGKILL или аварии ОС может остаться приватный временный файл либо полностью
записанный конечный файл без сообщения об успехе. Приёмник не пытается удалять
неизвестные остатки или перезаписывать существующий ключ. `E_ALREADY_EXISTS`
требует отдельной проверки существующего файла без вывода его содержимого.
Getpass защищает вывод терминала и историю команд, но не даёт гарантии против
внутреннего журналирования ввода провайдером терминала или чтения памяти
процесса привилегированным пользователем. Python не гарантирует обнуление строк
в памяти после завершения процесса.

Локальная проверка, включая реальный PTY без эха:

```bash
python -I -B cloud/task088_v5_access/test_provision_read_credential.py
```

В тестах используется вымышленная строка, не являющаяся рабочим ключом.
