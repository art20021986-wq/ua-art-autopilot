# JAPAN-LHD-001 — машины с японских аукционов, только левый руль (разведка, 2026-11-26)

Сессия 41. Задача владельца 26.11: показывать с аукционов Японии только машины с левым рулём
(водитель слева). Только разведка: сайт, CRM, сервер не трогались, проб на сервере не запускалось.

## 1. Откуда законно брать лоты

| Источник | Что это | Можно ли показывать на сайте |
|---|---|---|
| Наш кабинет jpauto.auction (BE FORWARD Live Auction) | Уже есть логин (секреты `JPAUTO_EMAIL`/`JPAUTO_PASSWORD`), по нему работает корейская лента. BE FORWARD заявляет 150+ японских аукционов, 100 000+ машин в неделю | Только для участия в торгах. Публичный показ — только с письменного разрешения BE FORWARD (их условий в открытом доступе нет: `/terms` — 404) |
| Своё членство в USS/TAA/CAA/JU | Нужна японская компания и лицензия на торговлю подержанными авто | Нет. Правила USS: информация аукциона принадлежит USS, члены используют её только для торгов, раскрывать не-членам запрещено (штраф, отключение) |
| Платные фиды (avto.jp / ajes, JPcenter от $188/мес., Carapis) | Посредники, перепродают данные лотов (XML/CSV/API) | Лицензии от аукционов не подтверждены. Сам avto.jp советует скрывать USS от анонимных пользователей; Carapis пишет, что API у USS нет и данные «парсятся». Не рекомендуется |

**Уточнение (координатор, 26.11):** у владельца есть договор/разрешение от jpauto.auction на показ их
машин — письмо не нужно. Остаётся проверить, что договор покрывает японские лоты; лоты USS публично
не показываем в любом случае (правила USS).

Прямо: автоматически собирать лоты и выкладывать их публично для всех — запрещено правилами USS
и, скорее всего, других аукционов. У jpauto.auction в robots.txt стоит `Disallow: /` для всех роботов
(это касается и уже работающей корейской ленты — вопрос к BE FORWARD тот же).

Законная схема (обычная у брокеров): мы участник торгов через BE FORWARD, клиенту
подбираем лоты под заявку, публично — только наши уже выкупленные машины или то, что BE FORWARD
разрешит письменно.

## 2. Как отбирать левый руль

1. **Поле «руль» в данных лота — основной способ.** На аукционном листе руль указан
   (LHD/RHD, по-японски ハンドル 左/右); в кабинете jpauto в корейском поиске уже есть флажок
   «Левый руль» (`left_hd[]`), в карточке лота — поле «руль». Японский раздел кабинета ещё не смотрели —
   нужна одна проба только на чтение.
2. **Подсказка по марке.** Левый руль в Японии — это в основном импорт: Mercedes, BMW, Porsche,
   Ferrari, Lamborghini, американские машины (Chevrolet, Cadillac, Jeep, Ford), часть Audi/VW/Volvo.
   Но современные Mercedes/BMW/Audi в Японии чаще с правым рулём — одной марки мало, только вместе с полем.
3. **Фото — только запасной вариант.** Фото салона есть не у каждого лота, часто снято с
   пассажирской стороны; ошибки неизбежны. Использовать только как вторую проверку перед покупкой
   (менеджер смотрит глазами), не как фильтр.

**Сколько лотов.** Точной открытой цифры нет. Оценка: 1–3% от 100–150 тыс. лотов в неделю —
примерно 1 000–3 000 машин с левым рулём в неделю (сходится с «более 2 000 LHD» у BE FORWARD
и ~1 000 LHD-лотов в каталоге одного польского импортёра). Точную цифру даст проба кабинета.

## 3. Варианты для владельца

**A. Подбор по заявке через наш кабинет BE FORWARD (рекомендую).**
- Данные: наш кабинет, фильтр «левый руль». Сначала одна проба только на чтение (японский поиск,
  число лотов LHD за неделю, поля) — через очередь координатора.
- Цена: 0 $ сверху (комиссии BE FORWARD — по их тарифу, как сейчас).
- Сроки: проба — 1 день; дальше — по выбору владельца.
- Клиент видит: на сайте форма «Подобрать машину с левым рулём из Японии»; менеджер присылает
  клиенту подходящие лоты лично. Публичной ленты нет.

**B. Публичная лента Японии (как Корея), только левый руль.**
- Если договор с jpauto.auction покрывает японские лоты. Лоты USS не показываем в любом случае.
- Цена: 0 $ сверху. Сроки: 1–2 недели (сборщик уже есть для Кореи).
- Клиент видит: вкладка «🇯🇵 Японія» на главной (сейчас «незабаром») — только левый руль, фото, год,
  пробег, оценка, цена «до Киева».

**C. Платный фид (avto.jp / JPcenter).**
- Цена: от ~$188 в месяц и выше. Сроки: 1–2 недели.
- Риск: лицензии от аукционов не подтверждены, USS по их же совету скрывать. Не рекомендую.
