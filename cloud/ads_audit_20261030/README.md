# ADS-AUDIT-20261030 — готовность к платной рекламе Google (кроме кредита/лизинга и цен «від»)

Только аудит (чтение репозитория, отчётов и требований Google). Сайт, CRM и реклама не менялись.
Основа: cloud/ads_tz_20261026 (ТЗ), cloud/google_ads_plan_20261025, cloud/gsc_report/20261026.json, cloud/latest_status.md.

## Сделано с 2026-10-25
- Счётчик GA4 G-6SRBQK6GY4 на всех страницах; ключевые события generate_lead (заявка) и contact (телефон/мессенджеры).
- Страницы моделей uk/ru: Kia K5, Hyundai Sonata, Tucson, Sportage, Santa Fe, «Авто з Японії»; карта сайта → Google, IndexNow.
- Короткая заявка (имя + телефон, модель сама) на 5 страницах Кореи и кнопка над «Розрахувати» на странице подбора.
- Страница подбора: галереи фото, поколения, надписи про руль для Японии.
- Доверие: отзывы и бейдж AUTO.RIA на главной.

## Не сделано — сайт (по важности для цены заявки)
1. Нет учёта источника заявки (gclid / utm → CRM). Без этого нельзя считать цену заявки по модели и
   передавать в Google «заявка стала продажей». Google рекомендует: сохранять gclid + телефон в заявке,
   enhanced conversions for leads, затем импорт продаж из CRM (с 15.06.2026 загрузки идут через Data Manager API).
2. Нет страницы «Політика конфіденційності». Сайт собирает имя и телефон; политика Google «Data collection and use»
   требует раскрытия, для форм заявок в объявлениях ссылка на политику обязательна.
3. Тексты моделей не совпадают с рекламой: Tucson/Sportage/Santa Fe перечисляют бензин/гибрид/дизель вместе;
   у K5/Sonata нет «газ LPI 2018–2023». Несовпадение объявления и страницы = дороже клик.
4. Нет отдельной страницы Nissan Note 2018–2023 (только общая «Авто з Японії»).
5. На страницах моделей нет доверия: отзывов, фото выданных машин этой модели.
6. (SEO, не реклама) украинские адреса страниц + hreflang; 15 карточек авто не в индексе.

## Не сделано — вне сайта (владелец)
- Аккаунт Google Ads, бюджет, платёжные и налоговые данные (НДС 20 %), проверка рекламодателя (документы компании).
- Профиль компании в Google (Карты) + отзывы → адрес и звонок в объявлениях.
- Объявления — на украинском: по закону о языке (ст. 32) мова реклами — державна.
